# Abstract

Transformer, 특히 causal 방식으로 input sequence 를 처리하는 decoder-only model 은 현대 deep learning 의 성공을 이끄는 주요 동력 중 하나이다. 하지만 sequence length 에 대해 training 시 quadratic 하게 scaling 되고, autoregressive generation 시 sequence length 에 선형인 크기의 cache 를 요구하는 등 efficiency 문제가 있다. 이에 attention layer 를 근사하려는 수많은 접근이 제안되었다.

한편, structured state-space model (SSM) 은 training 시 sequence length 에 대해 linear scaling 을 가지며, generation 시 constant 한 state size 를 갖는 대안적 sequence model 로 등장했다. 이들은 long-range task 에서 강한 성능을 보였고, 최근에는 small to moderate scale 의 language modeling 에서 Transformer 와 맞먹거나 이를 능가했다. 그러나 SSM 의 발전은 Transformer 를 이론적으로 이해하고 현대 hardware 에서 최적화하려는 커뮤니티의 집단적 노력과는 분리되어 나타난 것으로 보인다. 그 결과, SSM 은 Transformer 에 비해 이해하고 실험하기가 더 어렵고, algorithm 및 system 관점 모두에서 Transformer 만큼 효율적으로 학습시키는 것도 여전히 어렵다.

저자의 주요 목표는 structured SSM 과 attention variant 사이의 풍부한 이론적 연결을 구축하는 것이다. 이는 원래 Transformer 를 위해 개발된 algorithm 및 system 최적화를 SSM 으로 이전할 수 있게 하며, sequence length 에 대해 더 효율적으로 scaling 되면서도 Transformer 보다 더 나은 성능을 보이는 foundation model 을 만드는 데 기여한다. 이 방향에서 중요한 이정표는 Linear Attention (LA) framework 이다. 이는 quadratic kernelized attention 의 “dual form” 과 특정 linear recurrence 의 동등성을 보임으로써, autoregressive attention 과 linear RNN 사이의 연결을 도출했다. 이러한 duality 는 efficient parallelizable training 과 efficient autoregressive inference 를 동시에 가능하게 한다. 같은 정신에서, 이 논문은 SSM 과 attention 의 장점을 결합하기 위해 linear-complexity SSM 과 quadratic-complexity form 을 연결하는 여러 관점을 제공한다.

저자의 **structured state space duality (SSD)** framework 는 structured SSM 과 attention variant 를 연결하며, 이는 subquadratic 한 parameter 수와 multiplication complexity 를 갖는 structured matrix 라는 추상화를 통해 이루어진다. 저자는 sequence model 을 표현하는 두 가지 큰 framework 를 전개하는데, 하나는 matrix transformation 으로, 다른 하나는 tensor contraction 으로 표현한다. 이 둘은 각각 duality 에 대한 서로 다른 관점을 드러낸다.

저자의 기술적 기여는 다음과 같다.

* 저자는 state space model 과 semiseparable matrix 라는 잘 연구된 structured matrix family 사이의 동등성을 보인다. 이 연결은 저자의 framework 의 핵심으로서, SSM 에 대한 새로운 성질과 algorithm 을 드러낸다. 이 논문의 중심 메시지 중 하나는 state space model 을 계산하는 서로 다른 방법들이 structured matrix 에 대한 다양한 matrix multiplication algorithm 으로 재구성될 수 있다는 점이다.
* 저자는 linear attention 이론을 크게 개선한다. 먼저 tensor contraction 의 언어를 통해 recurrent form 에 대한 날카로운 증명을 제시하고, 이어서 이를 새로운 family 인 structured masked attention (SMA) 으로 일반화한다.
* 저자는 SSM 과 SMA 를 연결하여, 이 둘이 서로 dual 인 큰 교집합을 가지며, SSM 과 유사한 linear form 과 attention 과 유사한 quadratic form 을 동시에 가진다는 것을 보인다. 또한 빠른 recurrent form 을 가지는 어떤 kernel attention method 도 반드시 SSM 이어야 함을 증명한다.

이 framework 는 그 자체의 이론적 가치뿐 아니라, sequence model 을 이해하고 개선하기 위한 넓은 방향성을 연다.

* **Efficient Algorithms.** 무엇보다 먼저, 이 framework 는 SSM 을 계산하기 위한 새롭고 효율적이며 구현이 쉬운 algorithm 을 드러낸다. 저자는 semiseparable matrix 의 block decomposition 에 기반한 새로운 SSD algorithm 을 도입하는데, 이는 linear SSM recurrence 와 quadratic dual form 을 모두 활용하여 training 및 inference compute, memory usage, 현대 hardware 의 matrix multiplication unit 활용 능력 등 주요 efficiency 축 전반에서 최적의 tradeoff 를 달성한다. SSD 의 전용 implementation 은 Mamba 의 최적화된 selective scan implementation 보다 $2 \sim 8\times$ 더 빠르며, 동시에 훨씬 더 큰 recurrent state size 를 허용한다. SSD 는 softmax attention 의 최적화된 implementation 과도 매우 경쟁력 있으며, sequence length 2 K 에서 성능이 교차하고, 16 K 에서는 6 배 더 빠르다.
* **Architecture Design.** SSM 과 같은 새로운 architecture 를 채택하는 데 있어 한 가지 주요 장애물은 large-scale training 을 위한 hardware-efficient optimization 및 parallelism 기법 등 Transformer 에 맞춰진 ecosystem 이다. 저자의 framework 는 attention 에서 확립된 관례와 기법을 사용하여 SSM 에 대한 architecture design choice 의 vocabulary 를 구축하고, 이를 더 개선할 수 있게 한다. 예를 들어, 저자는 multi-head attention (MHA) 의 head 와 대응되는 개념을 SSM 에 도입한다. 저자는 Mamba architecture 가 multi-input SSM (MIS) 이며, 이것이 multi-value attention (MVA) 과 유사하다는 것을 보이고, 서로 다른 head structure 를 가진 다른 Mamba variant 와 비교한다.
* 저자는 또한 이러한 아이디어를 사용해 Mamba block 에 약간의 수정을 가하며, 이를 통해 tensor parallelism 이 구현될 수 있게 한다. 핵심 아이디어는 grouped-value attention (GVA) head structure 를 도입하고, 모든 data-dependent projection 이 block 시작부에서 병렬로 일어나도록 옮기는 것이다.
* 수정된 parallel Mamba block 과 내부 SSM layer 로서 SSD 를 함께 사용한 결과가 **Mamba-2** architecture 이다. 저자는 Mamba 와 동일한 setting 에서 Mamba-2 의 Chinchilla scaling law 를 조사하고, perplexity 와 wall-clock time 양쪽에서 Mamba 와 Transformer++ 를 Pareto 지배함을 발견한다. 또한 Pile 에서 다양한 크기의 Mamba-2 model family 를 학습시켜, standard downstream evaluation 에서 Mamba 및 open source Transformer 와 맞먹거나 이를 능가함을 보인다. 예를 들어, Pile 에서 300 B token 으로 학습한 2.7 B parameter 의 Mamba-2 는 같은 dataset 에서 학습한 Mamba-2.8B, Pythia-2.8B, 심지어 Pythia-6.9B 보다도 더 좋은 성능을 보인다.
* **Systems Optimizations.** SSD framework 는 SSM 과 Transformer 를 연결하여, Transformer 를 위해 개발된 풍부한 system optimization 연구를 활용할 수 있게 한다.

  * 예를 들어, Tensor Parallelism (TP) 은 같은 node 내 GPU 들에 각 layer 를 분할하여 large Transformer model 을 학습시키는 중요한 model parallelism 기법이다. 저자는 Mamba-2 를 TP 친화적으로 설계하여, block 당 synchronization point 수를 절반으로 줄인다.
  * activation 이 하나의 device 에 들어가지 않는 매우 긴 sequence 에 대해서는 attention block 을 위한 sequence parallelism 이 개발되었다. 저자는 recurrent state 를 device 사이에서 전달함으로써, 일반적인 SSM 과 특히 Mamba-2 를 sequence parallelism 으로 학습하는 방법을 설명한다.
  * 길이가 서로 다른 example 로 finetuning 할 때 최적의 efficiency 를 위해, Transformer 는 padding token 을 제거하고 variable length sequence 에 대해 attention 을 수행하기 위한 정교한 기법을 필요로 한다. 저자는 Mamba-2 가 padding token 없이도 variable sequence length 를 효율적으로 학습할 수 있음을 보인다.

Sec. 9 에서는 language modeling, training efficiency, 그리고 어려운 multi-query associative recall task 에서 Mamba-2 를 실험적으로 검증한다. 마지막으로 Sec. 10 에서는 확장된 related work 를 제공하고, 저자의 framework 가 열어 주는 잠재적 연구 방향을 논의한다.

# 1 Introduction

* 예를 들어, training 동안 sequence length 에 대해 quadratic 하게 scaling 되고,
* autoregressive generation 동안에는 sequence length 에 선형인 크기의 cache 를 요구한다.

이와 병렬적으로, training 시 sequence length 에 대해 linear scaling 을 가지며 generation 시 constant 한 state size 를 갖는 대안적 sequence model class 인 structured state-space model (SSM) 이 등장했다.

* 이들은 long-range task 에서 강한 성능을 보인다.
* 최근에는 small to moderate scale 의 language modeling 에서 Transformer 와 맞먹거나 이를 능가했다.

그러나 SSM 의 발전은 Transformer 를 개선하려는 커뮤니티의 집단적 노력과 분리되어 나타난 것으로 보인다.

* 여기에는 Transformer 를 이론적으로 이해하려는 노력과,
* 현대 hardware 에서 이를 최적화하려는 노력이 포함된다.

# 2 Background and Overview

## 2.1 Structured State Space Models

Structured state space sequence model (S4) 은 deep learning 을 위한 최근의 sequence model class 로, RNN, CNN, 그리고 고전적인 state space model 과 넓게 관련되어 있다. 이들은 1-dimensional sequence $x \in \mathbb{R}^{T} \mapsto y \in \mathbb{R}^{T}$ 를 암묵적인 latent state $h \in \mathbb{R}^{(T,N)}$ 를 통해 사상하는 특정 continuous system 에서 영감을 받았다.

structured SSM 의 일반적인 discrete form 은 식 (1) 의 형태를 가진다.

$$
h_t = A h_{t-1} + B x_t
\tag{1a}
$$

$$
y_t = C^\top h_t
\tag{1b}
$$

$$
h_t = A_t h_{t-1} + B_t x_t
\tag{2a}
$$

$$
y_t = C_t^\top h_t
\tag{2b}
$$

여기서 $A \in \mathbb{R}^{(N,N)}$, $B \in \mathbb{R}^{(N,1)}$, $C \in \mathbb{R}^{(N,1)}$ 이다. Structured SSM 이라는 이름은 temporal dynamics 를 제어하는 $A$ matrix 가 deep neural network 에서 사용할 수 있을 만큼 효율적으로 이 sequence-to-sequence transformation 을 계산하려면 structured 해야 하기 때문에 붙여졌다. 처음 도입된 structure 는 diagonal plus low-rank (DPLR) 와 diagonal 이며, 후자는 여전히 가장 널리 사용되는 structure 이다.

이 논문에서 저자는 state space model (SSM) 이라는 용어를 structured SSM 을 가리키는 데 사용한다. 이러한 SSM 에는 여러 가지 변형이 있으며, continuous-time, recurrent, convolutional model 과 같은 neural sequence model 의 주요 paradigm 과 깊은 관련이 있다. 아래에서 저자는 간단한 개요를 제공하고, 더 많은 맥락과 세부사항은 선행 연구를 참고하도록 한다.

#### Continuous-time Models

원래의 structured SSM 은 sequence 에 직접 작동하기보다, $x(t) \in \mathbb{R} \mapsto y(t) \in \mathbb{R}$ 인 function 에 대한 continuous-time map 으로 시작되었다. continuous-time 관점에서 식 (1a) 의 matrix $(A, B)$ 는 직접 학습되는 것이 아니라, parameterized 된 step size $\Delta$ 와 함께 기저 parameter $(\mathring{A}, \mathring{B})$ 로부터 생성된다. “continuous parameter” $(\Delta, \mathring{A}, \mathring{B})$ 는 고정된 공식 $A = f_A(\Delta, \mathring{A})$ 와 $B = f_B(\Delta, \mathring{B})$ 를 통해 “discrete parameter” $(A, B)$ 로 변환되며, 쌍 $(f_A, f_B)$ 를 discretization rule 이라고 부른다.

#### Remark 1

저자의 주요 model 은 선행 연구와 같은 parameterization 및 discretization step 을 채택하지만, 설명과 표기 단순화를 위해 이 논문의 나머지 부분에서는 이를 생략한다. 또한 structured SSM 에 대한 선행 연구에서는 continuous parameter $(\mathring{A}, \mathring{B})$ 와 discrete parameter $(A, B)$ 를 대신 각각 $(A, B)$ 와 $(\bar{A}, \bar{B})$ 로 표기했지만, 저자는 presentation 을 단순화하고 주요 SSM recurrence 를 지배하는 discrete parameter 에 직접 초점을 맞추기 위해 표기를 변경했다.

#### Recurrent Models

식 (1) 과 식 (2) 는 input $x$ 에 대해 linear 한 recurrence 의 형태를 가진다. 따라서 structured SSM 은 recurrent neural network (RNN) 의 한 유형으로 볼 수 있으며, 이 linearity 는 추가적인 성질을 부여하고 전통적인 RNN 의 순차 계산을 피할 수 있게 한다. 반대로, 이러한 단순화에도 불구하고 SSM 은 여전히 sequence transformation 으로서 완전한 표현력을 가진다. 이는 universal approximation 의 의미에서 성립한다.

#### Convolutional Models

식 (1) 처럼 SSM 의 dynamics 가 시간에 따라 constant 하면, 이 model 을 linear time-invariant (LTI) 라고 부른다. 이 경우, 이는 convolution 과 동등하다. 따라서 SSM 은 CNN 의 한 유형으로도 볼 수 있지만, 다음의 차이가 있다.

* convolution kernel 이 SSM parameter $(A, B, C)$ 를 통해 암묵적으로 parameterized 된다.
* convolution kernel 이 일반적으로 local 하지 않고 global 하다.

반대로, 고전적인 signal processing theory 를 통해 충분히 well-behaved 한 convolution 은 모두 SSM 으로 표현될 수 있다.

일반적으로, 이전의 LTI SSM 은 efficient parallelizable training 을 위해 convolutional mode 를 사용하고, efficient autoregressive inference 를 위해 recurrent mode 인 식 (1) 로 전환했다. 여기서 training 에서는 전체 input sequence 를 미리 볼 수 있고, inference 에서는 input 을 한 번에 한 step 씩 본다.

#### Selective State Space Models

parameter $(A, B, C)$ 가 시간에 따라 변할 수도 있는 식 (2) 의 형태는 Mamba 에서 selective SSM 으로 도입되었다. 표준적인 LTI formulation 인 식 (1) 과 비교하면, 이 model 은 각 timestep 에서 input 에 선택적으로 집중하거나 이를 무시할 수 있다. 이 model 은 language 와 같은 information-dense data 에서 LTI SSM 보다 훨씬 더 좋은 성능을 보이며, 특히 더 많은 information capacity 를 허용하도록 state size $N$ 이 증가할수록 더욱 그렇다는 것이 보였다. 그러나 이 model 은 convolutional mode 가 아니라 recurrent mode 에서만 계산될 수 있으며, 효율적이기 위해서는 hardware-aware implementation 이 필요하다. 그럼에도 불구하고, modern accelerator 인 GPU 와 TPU 가 특화되어 있는 matrix multiplication unit 을 활용하지 못하기 때문에, CNN 이나 Transformer 와 같은 hardware-friendly model 보다 여전히 덜 효율적이다.

time-invariant SSM 은 continuous, recurrent, convolutional sequence model 과 밀접하게 관련되어 있지만, attention 과 직접적으로 관련되어 있지는 않다. 이 논문에서 저자는 selective SSM 과 attention 사이에 더 깊은 관계가 있음을 보이고, 이를 사용하여 SSM 의 training speed 를 크게 개선하는 동시에 훨씬 더 큰 state size $N$ 을 허용한다.

#### Structured SSMs as Sequence Transformations

**Definition 2.1.** 저자는 sequence transformation 이라는 용어를, sequence 에 대한 parameterized map $Y = f_\theta(X)$ 를 가리키는 데 사용한다. 여기서 $X, Y \in \mathbb{R}^{(T,P)}$ 이고 $\theta$ 는 임의의 parameter 집합이다. $T$ 는 sequence 또는 time axis 를 나타내며, 아래첨자는 첫 번째 dimension 에 대한 indexing 을 뜻한다. 예를 들어 $X_t, Y_t \in \mathbb{R}^{P}$ 이다.

sequence transformation, 예를 들어 SSM 이나 self-attention 은 deep sequence model 의 초석이며, 여기서 이들은 Transformer 와 같은 neural network architecture 안에 포함된다. 식 (1) 또는 식 (2) 의 SSM 은 $P = 1$ 인 sequence transformation 이다. 이는 이 dimension 에 대해 broadcasting 함으로써 간단히 $P > 1$ 로 일반화할 수 있다. 다시 말해, input 을 $P$ 개의 독립적인 sequence 로 보고 각 sequence 에 SSM 을 적용하는 것이다. $P$ 는 head dimension 으로 생각할 수 있으며, 이는 Sec. 7 에서 더 자세히 설명한다.

**Definition 2.2.** 저자는 SSM operator $\mathrm{SSM}(A, B, C) = \mathrm{SSM}(A_{0:T}, B_{0:T}, C_{0:T})$ 를 식 (2) 로 정의되는 sequence transformation $X \in \mathbb{R}^{(T,P)} \mapsto Y \in \mathbb{R}^{(T,P)}$ 로 정의한다.

SSM 에서 $N$ dimension 은 state size 또는 state dimension 이라고 불리는 자유 parameter 이다. 저자는 이를 state expansion factor 라고도 부르는데, 이는 input/output 의 크기를 $N$ 배 확장하며, 이러한 model 의 computational efficiency 에 영향을 주기 때문이다.

마지막으로, attention 과 같은 많은 유형의 sequence transformation 은 sequence dimension 에 대한 단일 matrix multiplication 으로 표현될 수 있음을 언급한다.

**Definition 2.3.** sequence transformation $Y = f_\theta(X)$ 가 $Y = M_\theta X$ 의 형태로 쓸 수 있다면, 저자는 이를 matrix transformation 이라고 부른다. 여기서 $M$ 은 parameter $\theta$ 에 의존하는 matrix 이다. 저자는 sequence transformation 을 matrix $M$ 과 동일시하며, 문맥상 명확할 때는 $\theta$ 에 대한 의존성을 종종 생략한다.

## 2.2 Attention

attention 은 넓게는 sequence 내의 모든 position 쌍에 score 를 할당하여, 각 element 가 나머지 element 에 “attend” 할 수 있게 하는 종류의 계산을 가리킨다. 지금까지 가장 흔하고 중요한 attention 변형은 softmax self-attention 이며, 이는 다음과 같이 정의할 수 있다.

$$
Y = \mathrm{softmax}(QK^\top) \cdot V
$$

여기서 $Q, K, V \in \mathbb{R}^{(T,P)}$ 이다. 쌍별 비교의 mechanism 은 $QK^\top$ 를 materialize 함으로써 유도되며, 이것이 attention 의 특징적인 quadratic training cost 를 초래한다.

많은 attention variant 가 제안되었지만, 모두 이러한 attention score 의 핵심을 공유하며, 여러 근사 방식만 다르다. 이 논문에서 가장 중요한 attention variant 는 linear attention 이다. 대략적으로, 이 family 의 method 는 softmax 를 kernel feature map 안으로 접어 넣어 제거하고, matrix multiplication 의 associativity 를 사용해 $(QK^\top) \cdot V = Q \cdot (K^\top V)$ 로 다시 쓴다. 또한 중요한 경우인 causal (autoregressive) attention 에서, causal mask 가 좌변에 $(L \circ QK^\top) \cdot V$ 로 포함될 때, 여기서 $L$ 은 lower-triangular 1 의 matrix 이며, 우변은 recurrence 로 전개될 수 있음을 보였다. RetNet 과 GateLoop 와 같은 몇몇 최근 및 동시대 연구는 이를 더 일반적인 형태의 $L$ 로 확장한다. 이 논문에서 저자의 structured masked attention formulation 은 이러한 아이디어를 강하게 일반화한다.

## 2.3 Structured Matrices

일반적인 matrix $M \in \mathbb{R}^{(T,T)}$ 는 표현하기 위해 $T^2$ 개의 parameter 가 필요하고, matrix-vector multiplication 과 같은 기본 연산을 수행하는 데 $\mathcal{O}(T^2)$ 시간이 필요하다. Structured matrix 는 다음을 만족하는 matrix 이다.

* 압축된 representation 을 통해 subquadratic, 이상적으로는 linear 한 수의 parameter 로 표현될 수 있다.
* 이 압축된 representation 에 직접 작동함으로써 빠른 algorithm, 특히 matrix multiplication algorithm 을 가진다.

아마도 structured matrix 의 가장 전형적인 family 는 sparse matrix 와 low-rank matrix 일 것이다. 그러나 Toeplitz, Cauchy, Vandermonde, butterfly matrix 와 같은 다른 family 도 많이 존재하며, 이들은 모두 efficient model 을 위해 machine learning 에서 사용되어 왔다. Structured matrix 는 효율적인 representation 과 algorithm 을 위한 강력한 추상화이다. 이 논문에서 저자는 SSM 이 이전에는 deep learning 에서 사용되지 않았던 또 다른 structured matrix class 와 동등하다는 것을 보이고, 이 연결을 사용해 효율적인 method 와 algorithm 을 도출한다.

## 2.4 Overview: Structured State Space Duality

이 논문은 SSM, attention, structured matrix 사이의 훨씬 더 풍부한 연결 framework 를 전개하지만, 저자는 주요 method 에 대한 간단한 요약을 제공한다. 이는 실제로 algorithm 측면에서 상당히 self-contained 하고 단순하다.

#### Recurrent (Linear) Form

state space dual (SSD) layer 는 selective SSM 인 식 (2) 의 특수한 경우로 정의될 수 있다. recurrence 또는 parallel scan 으로서 SSM 을 계산하는 표준 계산을 적용할 수 있으며, 이는 sequence length 에 대해 linear complexity 를 가진다. Mamba 에서 사용된 version 과 비교할 때, SSD 는 두 가지 작은 차이가 있다.

* $A$ 에 대한 structure 가 diagonal 에서 scalar times identity structure 로 더 단순화된다. 이 경우 각 $A_t$ 는 단지 scalar 하나로도 식별될 수 있다.
* 저자는 Mamba 에서 사용된 $P = 1$ 과 비교해 더 큰 head dimension $P$ 를 사용한다. 일반적으로 $P = {64, 128}$ 가 선택되며, 이는 modern Transformer 의 관례와 유사하다.

원래 selective SSM 과 비교하면, 이러한 변화는 expressive power 를 약간 줄이는 대신 training efficiency 를 크게 개선하는 것으로 볼 수 있다. 특히, 저자의 새로운 algorithm 은 modern accelerator 의 matrix multiplication unit 을 사용할 수 있게 한다.

#### Dual (Quadratic) Form

SSD 의 dual form 은 attention 과 밀접하게 관련된 quadratic computation 으로, 다음과 같이 정의된다.

$$
(L \circ QK^\top) \cdot V
$$

$$
L_{ij} =
\begin{cases}
a_i \times \cdots \times a_{j+1} & i \ge j \
0 & i < j
\end{cases}
$$

여기서 $a_i$ 는 $[0,1]$ 범위로 bounded 된 input-dependent scalar 이다.

표준적인 softmax attention 과 비교하면, 두 가지 주요 차이가 있다.

* softmax 가 제거된다.
* attention matrix 가 추가적인 mask matrix $L$ 과 elementwise multiplication 된다.

이 두 변화는 모두 vanilla attention 의 문제를 다루는 것으로 볼 수 있다. 예를 들어, softmax 는 최근 “attention sink” 현상과 같은 attention score 의 문제를 일으키는 것으로 관찰되었다. 더 중요하게는, mask matrix $L$ 은 Transformer 의 heuristic positional embedding 을, 시간에 따라 얼마나 많은 information 이 전달될지를 제어하는 다른 data-dependent positional mask 로 대체하는 것으로 볼 수 있다.

더 넓게 보면, 이 형태는 Sec. 4 에 정의되는 linear attention 의 일반화인 structured masked attention 의 한 예시이다.

#### Matrix Form and SSD Algorithm

SSD 의 다양한 form 은 unified 된 matrix representation 을 통해 연결된다. 즉, SSM 이 $\theta = (A, B, C)$ 에 의존하는 matrix $M_\theta \in \mathbb{R}^{(T,T)}$ 에 대해 $Y = MX$ 라는 matrix transformation form 을 가진다는 것을 보인다. 특히, SSD 의 dual form 은 matrix $M$ 에 의한 순진한 quadratic-time multiplication 과 동등하며, recurrent form 은 $M$ 의 structure 를 활용하는 특정한 효율적인 linear-time algorithm 이다.

이를 넘어서, $M$ 에 의한 multiplication 을 위한 어떤 algorithm 이든 적용될 수 있다. 저자가 제안하는 hardware-efficient SSD algorithm 은 $M$ 의 block decomposition 을 포함하는 새로운 structured matrix multiplication method 이며, 순수 linear form 이나 quadratic form 보다 더 나은 efficiency tradeoff 를 얻는다. 이는 일반 selective SSM 과 비교해 상대적으로 단순하고 구현하기 쉽다. # 3 State Space Models are Structured Matrices

이 section 은 state space model 을 sequence transformation 으로 보는 서로 다른 관점을 탐구하고, 이러한 map 의 성질과 algorithm 을 개괄한다. 이 section 의 주요 result 는 state space model 과 semiseparable matrix 라고 불리는 structured matrix family 사이의 동등성에 관한 것이며, 이는 새로운 efficiency result 를 함의한다.

## 3.1 The Matrix Transformation Form of State Space Models

저자의 SSM 정의는 식 (2) 를 통해 정의되는 parameterized map 임을 상기하자. 저자의 이론적 framework 는 이 transformation 을 단순히 vector $x \in \mathbb{R}^{T} \mapsto y \in \mathbb{R}^{T}$ 를 사상하는 matrix multiplication 으로 쓰는 것에서 시작한다.

정의에 의해, $h_0 = B_0 x_0$ 이다. 귀납적으로,

$$
h_t = A_t \cdots A_1 B_0 x_0 + A_t \cdots A_2 B_1 x_1 + \cdots + A_t A_{t-1} B_{t-2} x_{t-2} + A_t B_{t-1} x_{t-1} + B_t x_t
$$

$$
= \sum_{s=0}^{t} A^\times_{t:s} B_s x_s .
$$

$y_t$ 를 만들기 위해 $C_t$ 를 곱하고, $t \in [T]$ 에 대해 식을 vectorize 하면, SSM 의 matrix transformation form 을 유도할 수 있다.

$$
y_t = \sum_{s=0}^{t} C_t^\top A^\times_{t:s} B_s x_s
$$

$$
y = \mathrm{SSM}(A, B, C)(x) = Mx
$$

$$
M_{ji} = C_j^\top A_j \cdots A_{i+1} B_i
\tag{3}
$$

## 3.2 Semiseparable Matrices

식 (3) 의 $M$ 은 semiseparable matrix 로 알려진 matrix class 의 특정 representation 이다. Semiseparable matrix 는 fundamental 한 matrix structure 이다. 저자는 먼저 이 matrix 와 그 성질을 정의한다.

**Definition 3.1.** lower triangular matrix $M$ 이 lower triangular 부분, 즉 diagonal 위가 아니라 diagonal 위를 제외한 diagonal 포함 아래쪽에 포함되는 모든 submatrix 의 rank 가 최대 $N$ 이면, $M$ 을 $N$-semiseparable 이라고 한다. 저자는 $N$ 을 semiseparable matrix 의 order 또는 rank 라고 부른다.

Definition 3.1 과, 관련된 다른 형태의 “separable” structure, 예를 들어 quasiseparable matrix 와 다른 semiseparable matrix 정의는, submatrix 에 대한 rank 조건으로 특징지어지기 때문에 structured rank matrix, 또는 rank-structured matrix 라고 불리기도 한다. Semiseparable matrix 는 hierarchical semiseparable (HSS), sequential semiseparable (SSS), Bruhat form 을 포함하는 많은 structured representation 을 가진다. 저자는 주로 SSS form 을 사용할 것이다.

### 3.2.1 The Sequentially Semiseparable (SSS) Representation

**Definition 3.2.** lower triangular matrix $M \in \mathbb{R}^{(T,T)}$ 가 다음 형태로 쓸 수 있으면, $N$-sequentially semiseparable (SSS) representation 을 가진다.

$$
M_{ji} = C_j^\top A_j \cdots A_{i+1} B_i
\tag{4}
$$

여기서 vector $B_0, \ldots, B_{T-1}, C_0, \ldots, C_{T-1} \in \mathbb{R}^{N}$ 과 matrix $A_0, \ldots, A_{T-1} \in \mathbb{R}^{(N,N)}$ 가 존재한다.

저자는 operator $\mathrm{SSS}$ 를 정의하여 $M = \mathrm{SSS}(A_{0:T}, B_{0:T}, C_{0:T})$ 가 되도록 한다.

semiseparable matrix 에 대한 fundamental result 는, 이들이 SSS representation 을 가진 matrix 와 정확히 동등하다는 점이다. 한 방향은 간단한 구성적 증명으로 도출할 수 있다.

**Lemma 3.3.** representation (4) 를 가진 $N$-SSS matrix $M$ 은 $N$-semiseparable 이다.

**Proof.** 임의의 off-diagonal block $M_{j:j',, i':i}$ 를 생각하자. 여기서 $j' > j \ge i > i'$ 이다. 이 block 은 다음과 같은 explicit 한 rank-$N$ factorization 을 가진다.

$$
\begin{bmatrix}
C_j^\top A^\times_{j:i'} B_{i'} & \cdots & C_j^\top A^\times_{j:i-1} B_{i-1} \
\vdots & \ddots & \vdots \
C_{j'-1}^\top A^\times_{j'-1:i'} B_{i'} & \cdots & C_{j'-1}^\top A^\times_{j'-1:i-1} B_{i-1}
\end{bmatrix}
$$

# $$

\begin{bmatrix}
C_j^\top A^\times_{j:j} \
\vdots \
C_{j'-1}^\top A^\times_{j'-1:j}
\end{bmatrix}
A^\times_{j:i-1}
\begin{bmatrix}
A^\times_{i-1:i'} B_{i'} & \cdots & A^\times_{i-1:i-1} B_{i-1}
\end{bmatrix}.
\tag{5}
$$

$\square$

식 (5) 는 sequence model 을 위한 저자의 fast algorithm 을 도출할 때 광범위하게 사용될 것이다. 다른 방향은 semiseparable matrix 문헌에서 잘 확립되어 있다.

**Proposition 3.4.** 모든 $N$-semiseparable matrix 는 $N$-SSS representation 을 가진다.

또한, Definition 3.2 는 representation 을 위해 $\mathcal{O}(N^2 T)$ 개의 parameter, 특히 $A$ matrix 를 저장하기 위한 parameter 를 포함하지만, 실제로는 이를 $\mathcal{O}(NT)$ parameter 로 압축할 수 있으며, 이는 asymptotically tight 하다. 따라서 이 논문의 나머지 부분에서 저자는 structured matrix class 자체와 그것의 특정 representation 을 혼용해서 사용할 것이다. 저자는 다른 후보 representation 대신 항상 이 representation 을 사용할 것이다. 이에 따라 저자는 SSS form 의 $N$-semiseparable matrix 를 가리키기 위해 $N$-SS 라는 표현을 사용할 것이다.

Semiseparable matrix 는 fundamental 한 matrix structure 이며 많은 중요한 성질을 가진다. 이들은 전반적인 recurrence 와 깊게 관련되어 있고, 서로 다른 연결과 효율적인 algorithm 을 드러내는 여러 characterization 으로 정의될 수 있다. 예를 들어 Definition 3.1 과 Definition 3.2 가 그러하다. 저자는 Appendix C.1 에서 다른 성질도 일부 언급한다.

**Remark 2.** semiseparability 의 개념은 매우 넓으며, 유사하지만 미묘하게 다른 많은 정의가 문헌에 등장한다. 저자의 정의는 다른 관례와 약간 다를 수 있다.

* 먼저, 이 논문에서 저자는 주로 causal 또는 autoregressive setting 에 관심이 있으므로, semiseparability 의 정의를 triangular case 로 제한했다.

  * 보다 형식적으로는, Definition 3.1 을 일부 저자들은 $(N, 0)$-semiseparability 라고 부를 수 있다.
* 일부 저자들은 이를 대신 quasiseparability 의 한 형태라고 부를 수도 있다.

간단한 survey 는 관련 문헌을 참고하라.

### 3.2.2 1-Semiseparable Matrices: the Scalar SSM Recurrence

저자는 1-SS matrix 의 special case 를 따로 다룬다. 이 경우, $C_j$ 와 $B_i$ 는 scalar 이며, SSS representation (4) 에서 바깥으로 factor out 할 수 있다. 이 경우 parameter 가 scalar 임을 강조하기 위해 lower-case 를 사용한다.

$$
\mathrm{SSS}(a, b, c) = \mathrm{diag}(c) \cdot M \cdot \mathrm{diag}(b)
\quad \text{where} \quad
M_{ji} = a^\times_{j:i}.
$$

diagonal matrix 는 다루기 쉽다. 예를 들어 diagonal matrix 에 의한 multiplication 은 elementwise scalar multiplication 과 같다. 따라서 저자는 이 항들을 무시할 수 있다. 그러므로 1-SS matrix 의 기본 representation 은 $M_{ji} = a_{j:i}$, 또는 다음과 같다.

$$
M = 1\mathrm{SS}(a_{0:T}) \coloneqq
\begin{bmatrix}
1 \
a_1 & 1 \
a_2 a_1 & a_2 & 1 \
\vdots & \vdots & \ddots & \ddots \
a_{T-1}\cdots a_1 & a_{T-1}\cdots a_2 & \cdots & a_{T-1} & 1
\end{bmatrix}.
\tag{6}
$$

1-SS matrix 의 중요성은 scalar recurrence 의 minimal form, 즉 state dimension $N = 1$ 이고 $(B, C)$ projection 이 없는 degenerate SSM case 와 동등하다는 데 있다. multiplication $y = Mx$ 는 다음 recurrence 로 계산될 수 있다.

$$
y_t = a_{t:0} x_0 + \cdots + a_{t:t} x_t
$$

$$
= a_t (a_{t-1:0} x_0 + \cdots + a_{t-1:t-1} x_{t-1}) + a_{t:t} x_t
$$

$$
= a_t y_{t-1} + x_t .
\tag{7}
$$

따라서 저자는 1-SS matrix 에 의한 matrix multiplication 을 scalar SSM recurrence, 또는 cumprodsum operator 라고도 부른다. 여기서 cumprodsum 은 cumulative product sum 의 뜻이며, cumulative product 와 cumulative sum 의 일반화이다. recurrence 의 fundamental form 으로서, 1-SS matrix 에 의한 multiplication 은 저자의 주요 algorithm 을 구성하는 building block 으로 중요하다.

저자는 이 논문의 중심 주제 중 하나가 sequence model 에 대한 많은 algorithm 이 structured matrix multiplication algorithm 으로 환원될 수 있다는 점임을 강조한다. 1-SS matrix 는 이 연결을 잘 보여준다.

* primitive scalar recurrence 또는 cumprodsum operator 를 계산하기 위한 많은 fast algorithm 이 존재한다.
* 그리고 이들 모두는 1-SS matrix 의 서로 다른 structured factorization 과 동등한 것으로 드러난다.

저자는 Appendix B 를 1-SS matrix multiplication 을 위한 이러한 algorithm 에 할애한다.

### 3.3 State Space Models are Semiseparable Matrices

저자의 SSM 정의는 Definition 2.1 을 통해 정의된 parameterized map 임을 상기하자. SSM 과 semiseparable matrix 사이의 연결은 이 transformation 을 vector $x \mapsto y \in \mathbb{R}^{T}$ 를 사상하는 matrix multiplication 으로 단순히 쓰는 것에서 따라온다.

식 (3) 은 state space model 과 sequentially semiseparable representation 사이의 연결을 직접 확립하며, 이는 다시 일반적인 semiseparable matrix 와 동등하다.

**Theorem 3.5.** state size $N$ 을 가진 state space model transformation $y = \mathrm{SSM}(A, B, C)(x)$ 는 sequentially semiseparable representation 의 $N$-SS matrix 에 의한 matrix multiplication $y = \mathrm{SSS}(A, B, C) \cdot x$ 와 동일하다.

다르게 말하면, sequence transformation operator $\mathrm{SSM}$ 은 matrix construction operator $\mathrm{SSS}$ 와 일치하며, 저자는 이들을 서로 바꾸어 사용한다. 또는 때때로 축약해서 $\mathrm{SS}$ 라고 쓴다. 더 나아가, 일종의 우연으로 structured state space model 과 sequentially semiseparable matrix 는 동일한 acronym 을 가지며, 이는 그들의 동등성을 더욱 부각한다. 편의상 저자는 SSM, SSS, SS 라는 acronym 을 각각 다음 의미로 서로 바꾸어 사용해도 모호함 없이 같은 개념을 가리킬 수 있다고 본다.

* SSM: state space model 또는 semiseparable matrix
* SSS: structured state space 또는 sequentially semiseparable
* SS: state space 또는 semiseparable

다만 일반적으로는 다음 관례를 사용한다.

* SSM 은 state space model 을 가리킨다.
* SS 는 semiseparable 을 가리킨다.
* SSS 는 sequentially semiseparable 을 가리킨다.

Fig. 2 는 state space model 을 semiseparable matrix 로 보는 sequence transformation 관점을 보여준다.

## 3.4 Computing State Space Models through Structured Matrix Algorithms

Theorem 3.5 가 중요한 이유는, SSM 과 다른 sequence model 을 효율적으로 계산하는 문제를 efficient structured matrix multiplication algorithm 문제로 환원할 수 있게 해주기 때문이다. 저자는 여기서 간단한 개요를 제공하고, Sec. 4 와 Sec. 5 에서 SSM 이 다른 sequence model 과 동등함을 보인 뒤, 주요한 새로운 algorithm 은 Sec. 6 으로 미룬다.

앞서 정의했듯이, semiseparable matrix, 즉 rank-structured matrix 는 고전적인 structured matrix 의 한 종류이다.

* 압축된 representation 을 가진다. 예를 들어 SSS form 은 $\mathcal{O}(T^2)$ 대신 $\mathcal{O}(T)$ 개의 parameter 만 가진다.
* 이 압축된 representation 에 직접 작동하는 fast algorithm 을 가진다.

또한 parameterization 과 matrix multiplication cost 는 semiseparable order 에 대해 tight 할 수 있다.

**Proposition 3.6.** 크기 $T$ 의 $N$-SS matrix 는 $\mathcal{O}(NT)$ 개의 parameter 로 표현될 수 있고, time 과 space 모두에서 $\mathcal{O}(NT)$ 의 matrix-vector multiplication 을 가진다.

예를 들어, 1-SS matrix 는 이 연결의 본질을 보여준다. Matrix $M = 1\mathrm{SS}(a)$ 는 정확히 $T-1$ 개의 parameter $a_{0:T-1} = a_1, \ldots, a_{T-1}$ 로 정의되며, scalar recurrence 인 식 (7) 을 따르면 $\mathcal{O}(T)$ 시간에 계산될 수 있다.

### 3.4.1 The Linear (Recurrent) Mode

Proposition 3.6 은 diagonal structured SSM, 즉 S4D 의 경우에 쉽게 확인할 수 있다. 단순히 state space model formulation 인 식 (2) 을 사용하고 recurrence 를 펼치면 된다. 저자는 formal 한 tensor-contraction algorithm 을 식 (8) 에 제시한다. 여기서 dimension $S$ 는 $T$ 와 같다.

$$
Z = \mathrm{contract}(SP, SN \to SPN)(X, B)
\qquad (S, P, N)
\tag{8a}
$$

$$
H = \mathrm{contract}(TSN, SPN \to TPN)(L, Z)
\qquad (T, P, N)
\tag{8b}
$$

$$
Y = \mathrm{contract}(TN, TPN \to TP)(C, H)
\qquad (T, P)
\tag{8c}
$$

여기서 $L \in \mathbb{R}^{(T,T)}$ 는 $1\mathrm{SS}(A)$ 로 정의된다. 다시 말해, 각 $i \in [N]$ 에 대해 $L_{0:T,0:T} = 1\mathrm{SS}(A_{0:T})$ 이다. 이 algorithm 은 식 (2) 에 대응하는 세 단계로 이루어진다.

* input matrix $B$ 로 input $X$ 를 확장한다. 식 (8a)
* 독립적인 scalar SSM recurrence 를 펼친다. 식 (8b)
* hidden state $H$ 를 output matrix $C$ 로 contraction 한다. 식 (8c)

식 (8b) 에서 scalar SSM 과 1-SS matrix 의 동등성을 사용했음을 주목하자.

**Remark 3.** 저자는 식 (8) 이 Mamba (S6) model 의 special case 임을 언급한다. 그러나 naive implementation 은 크기 $(T, P, N)$ 의 확장된 tensor $Z$ 와 $H$ 때문에 느리다. 이를 피하기 위해 hardware-aware implementation 이 도입되었다.

놀랍게도, Theorem 3.5 와 Proposition 3.6 은 즉시 모든 SSM 이 식 (8) 과 같은 asymptotic efficiency 를 가진다는 것을 함의한다.

**Theorem 3.7.** sequence length $T$ 에서 state size $N$ 인 임의의 state space model 은 $\mathcal{O}(TN)$ 시간에 계산될 수 있다. 여기서는 potential preprocessing 은 고려하지 않는다.

저자는 이 result 가 structured SSM 문헌에서는 새로운 것임을 언급한다. 특히 dense 하고 unstructured 한 $A_t$ matrix 가 주어졌을 때, 전체 representation 만 해도 크기가 $\mathcal{O}(TN^2)$ 인 것처럼 보인다. 따라서 Theorem 3.7 은 preprocessing step 이 있으면 unstructured SSM 조차도 최적으로 효율적으로 계산될 수 있다는 비자명한 결과를 말한다. 그 upper bound 는 $B$ 와 $C$ 의 크기가 주는 lower bound 인 $\mathcal{O}(TN)$ 과 일치한다.

**Remark 4.** Theorem 3.7 은 $\mathbb{R}^{(N,N)}$ 위의 거의 모든 dense matrix 가 $\mathbb{C}$ 위에서 diagonalizable 하다는 사실을 고려하면 아주 놀라운 것은 아닐 수도 있다. 이는 거의 모든 dense real SSM 이 diagonal complex SSM 과 동등하다는 결과로 이어진다. 이 사실은 diagonal SSM 이 structured SSM 의 가장 인기 있는 형태인 이유를 뒷받침한다. 그러나 Theorem 3.7 은 모든 real SSM 에 대해, 그리고 $\mathbb{C}$ 자체를 포함한 다른 field 위의 dense SSM 에 대해서도 성립하는 훨씬 더 강한 결과를 함의한다.

실제로 효율적으로 계산 가능한 SSM 은 여전히 $A$ 에 대한 추가 structure 가 필요하다. 특히 expensive 한 preprocessing step 을 피하기 위해서 그렇다. 이 preprocessing 은 $N$ order 의 추가 FLOPs 를 가지며, singular value decomposition 과 같은 hardware-inefficient 연산도 포함한다. 이러한 structure 는 기존 structured SSM 연구와 저자의 새로운 algorithm 이 모두 초점을 맞추는 대상이다. 특히 $A$ 에 약간 더 강한 structure 를 부여하면, Sec. 6 에서 SSM matrix $M = \mathrm{SSS}(A, B, C)$ 의 block decomposition 을 통해 매우 hardware-efficient 한 algorithm 을 설계할 수 있다.

### 3.4.2 The Quadratic (Naive) Mode

저자는 새로운 matrix 관점이 드러내는 SSM 계산의 또 다른 방법이 있음을 언급한다. Matrix SSM representation 인 식 (3) 을 naive 하게 계산하는 것은, sequence transformation matrix $M = \mathrm{SSS}(A, B, C)$ 를 단순히 materialize 하는 것이다. 이는 $(T, T)$ matrix 이므로, 이 naive algorithm 은 sequence length 에 대해 quadratic 하게 scaling 된다. 그러나 sequence length $T$ 가 짧을 때는, 상수항과 hardware-friendly 한 computation pattern, 예를 들어 matrix-matrix multiplication 활용 덕분에 이 방식이 linear algorithm 보다 실제로 더 효율적일 수 있다. 실제로 structured SSM 의 특정 case 에서는 이것이 quadratic attention computation 과 매우 유사하게 보인다.

### 3.4.3 Summary

많은 sequence model 은 명시적으로 matrix sequence transformation 으로 동기부여되거나 정의된다. 가장 대표적인 것은 Transformer 이며, 여기서 matrix mixer 는 attention matrix 이다. 반면, RNN 과 SSM 은 이전에는 이러한 방식으로 기술되지 않았다. 저자는 state space model 의 명시적인 matrix transformation form 을 제공함으로써, 이를 이해하고 사용하는 새로운 방식을 드러낸다. 계산 관점에서, state space model 의 forward pass 를 계산하는 모든 method 는 semiseparable matrix 에 대한 matrix multiplication algorithm 으로 볼 수 있다. Semiseparable matrix 관점은 state space duality (SSD) 를 바라보는 하나의 lens 를 제공하며, 여기서 dual mode 는 각각 linear-time semiseparable matrix multiplication algorithm 과 quadratic-time naive matrix multiplication 을 가리킨다.

더 나아가, semiseparable matrix 의 풍부한 structure 를 활용하면 더 나은 algorithm 과 더 많은 통찰을 얻을 수 있다. 저자는 Appendix C.1 에서 semiseparable matrix 의 추가 성질 일부를 설명한다.

## 4.1 The Attention Framework

### 4.1.1 Attention

basic 한 single-head attention 의 형태는 세 개의 vector sequence $(Q, K, V) \mapsto Y$ 에 대한 map 이다.

$$
Q = \text{input} \qquad (T, N)
$$

$$
K = \text{input} \qquad (S, N)
$$

$$
V = \text{input} \qquad (S, P)
$$

$$
G = QK^\top \qquad (T, S)
$$

$$
M = f(G) \qquad (T, S)
$$

$$
Y = GV \qquad (T, P)
\tag{9}
$$

저자는 tensor 의 dimension 을 나타내기 위해 “shape annotation” 을 사용한다. 예를 들어 $Q \in \mathbb{R}^{(T,N)}$ 와 같다. 이 일반적인 form 에서 $S$ 와 $T$ 는 각각 source 와 target sequence length 를 나타내고, $N$ 은 feature dimension, $P$ 는 head dimension 을 나타낸다.

가장 흔한 softmax attention variant 는 $G$ matrix 의 row 를 normalize 하기 위해 softmax activation $f = \mathrm{softmax}$ 를 사용한다.

### 4.1.2 Self-Attention

저자의 논의는 self-attention 의 가장 중요한 경우에서 동기부여된다. 이 경우는 다음과 같다.

* source sequence 와 target sequence 가 같다. 즉 $S = T$ 이다.
* 보통 feature dimension 과 head dimension 이 같다. 즉 $N = P$ 이다.
* $Q, K, V$ 는 같은 input vector 에 대한 linear projection 으로 생성된다. 즉 $Q = W_Q \cdot X$, $K = W_K \cdot X$, $V = W_V \cdot X$ 이다.

그러나 저자의 설명은 이러한 선택을 추상화하고, $Q, K, V$ matrix 자체에서 시작한다.

**Remark 5.** 저자의 초점은 equal head and feature dimension 을 가지는 self-attention case, 즉 $S = T$ 이고 $N = P$ 인 경우에 있다. 이는 running example 로 사용되어야 한다. 저자가 attention 의 general formulation 을 정의하는 이유는, 저자의 framework 가 cross-attention 과 같은 variant 도 포착할 수 있게 하기 위함일 뿐 아니라, dimension 에 대한 표기, 예를 들어 $S$ 와 $T$ 를 분리하면, 이 section 의 주요 result 에 대한 contraction notation 증명이 더 명확해지기 때문이다.

**Remark 6.** attention 은 보통 세 input $Q, K, V$ 에 대한 연산으로 framed 되며, 이들이 대칭적으로 보이지만, 식 (9) 의 input 과 output dimension 은 그렇지 않음을 보여준다. 특히 feature dimension $N$ 은 output 에 존재하지 않는다. 따라서 $S = T$ 인 경우, 예를 들어 self-attention 에서는 저자는 $V$ 를 main input 으로 본다. 그러면 식 (9) 는 proper 한 sequence transformation $V \mapsto Y$ 를 정의한다.

### 4.1.3 Kernel Attention

Gram matrix $G$ 에 softmax function 을 적용하는 단계는 두 부분으로 분해될 수 있다.

1. $G$ matrix 에 exponentiation 을 적용한다.
2. $S$ axis 에 대해 $G$ matrix 를 normalize 한다.

저자는 당장은 normalization term 을 무시할 수 있다고 본다. 이는 단순히 $V = 1$ 을 넣고 나누는 것에 해당하기 때문이다. 저자는 이것을 Sec. 7.3 에서 다시 다룬다. exponentiation term 은 kernel transformation 으로 볼 수 있다. 즉, 어떤 무한 차원의 feature map $\phi$ 가 존재해서 다음이 성립한다.

$$
\exp(QK^\top) = \phi(Q)\phi(K)^\top
$$

feature map 을 $Q$ 와 $K$ 자체의 정의 안으로 추상화함으로써, 다시 말해 $Q, K$ 를 transformation 이후의 version 으로 정의함으로써, 저자는 softmax transformation 을 무시할 수 있고, $Q, K$ 가 kernel feature map 에 의해 임의로 생성되며 잠재적으로 $N \ne P$ 임을 가정할 수 있다.

많은 kernel attention instantiation 이 제안되었다.

* 원래의 Linear Attention 은 kernel feature map 을 임의의 pointwise activation function 으로 정의한다. 예를 들어 $x \mapsto 1 + \mathrm{elu}(x)$ 와 같다.
* Random Feature Attention (RFA) 는 Gaussian kernel 의 random Fourier feature approximation 을 사용해 softmax attention, 즉 exp feature map 을 근사하도록 kernel feature map 을 선택한다. 이는 random projection, 즉 $Q$ 와 $K$ 에 random projection $W$ 를 곱한 뒤 activation $x \mapsto (\cos(x), \sin(x))$ 를 적용하는 것을 포함한다.
* Performer 는 FAVOR+ 를 제안한다. positive random features (PRF) 부분은 kernel feature map 을 random projection 뒤에 $x \mapsto 2^{-1/2}(\exp(x), \exp(-x))$ 를 적용하는 것으로 선택한다.

  * 이 선택은 kernel element 가 positive-valued 가 되도록 동기부여되며, softmax attention 을 provably approximate 한다.
  * 또한 orthogonal direction 으로 random projection 을 선택하는 것도 제안하지만, 저자는 이를 고려하지 않는다.
* cosFormer 는 positional information 을 통합하여 locality 를 강조하는 cosine reweighting mechanism 으로 RFA 를 확장한다. 이는 사실상 $Q_t, K_t$ 를 다음 feature map 에 통과시키는 것과 같다.
  $$
  x \mapsto (x \cos(\pi t / 2T), \sin(\pi t / 2T))
  $$
* Linear Randomized Attention 은 importance sampling 관점에서 RFA 를 일반화하고, 전체 softmax kernel 에 대해 더 나은 estimate 를 제공하도록 일반화한다. 이는 단지 exp-transformed numerator 만이 아니다.

다른 관련 attention variant 로는 Linformer 와 Nyströformer 가 있다. 이들은 모두 attention matrix $M$ 의 low-rank approximation 을 사용하며, 따라서 식 (9) 와 compatible 하다. 각각 random projection, 즉 Johnson-Lindenstrauss 와 kernel approximation, 즉 Nyström method 를 사용한다.

### 4.1.4 Masked (Kernel) Attention

shape 이 $(T, S)$ 인 mask $L$ 을 두자. 가장 흔하게는, autoregressive self-attention case 에서 $S = T$ 일 때, $L$ 은 causal mask 를 나타내는 lower-triangular 1 의 matrix 일 수 있다. causality 를 강제하는 것 외에도, 여러 종류의 다른 mask 가 적용될 수 있다. 특히 banded, dilated, block diagonal 과 같은 다양한 sparsity pattern 이 가능하며, 이는 dense attention 의 complexity 를 줄이기 위해 동기부여된다.

masked attention 은 보통 matrix notation 으로 다음과 같이 쓴다.

$$
y = (L \circ (QK^\top)) \cdot V
\tag{10}
$$

더 정확히 말해, shape annotation 을 붙이고 이를 정확한 계산 순서로 나누면 다음과 같다.

$$
G = QK^\top \qquad (T, S)
$$

$$
M = G \circ L \qquad (T, S)
$$

$$
Y = MV \qquad (T, P)
\tag{11}
$$

이 section 에서 저자의 attention variant 에 대한 개선된 유도는, 이 공식이 하나의 contraction 으로 쓸 수 있다는 점에서 시작한다.

$$
Y = \mathrm{contract}(TN, SN, SP, TS \to TP)(Q, K, V, L)
\tag{12}
$$

그리고 식 (11) 의 algorithm 은 pairwise contraction 의 특정 순서로 식 (12) 를 계산하는 것으로 다시 framed 될 수 있다.

$$
G = \mathrm{contract}(TN, SN \to TS)(Q, K)
\qquad (T, S)
\tag{13a}
$$

$$
M = \mathrm{contract}(TS, TS \to TS)(G, L)
\qquad (T, S)
\tag{13b}
$$

$$
Y = \mathrm{contract}(TS, SP \to TP)(M, V)
\qquad (T, P)
\tag{13c}
$$

## 4.2 Linear Attention

Linear attention 과 많은 다른 efficient attention variant 는 종종 핵심 attention computation 에서 matrix associativity 의 순서를 바꾸는 것으로 동기부여된다.

$$
(QK^\top)V = Q(K^\top V)
$$

그러나 mask 가 추가되면, 유도는 다소 덜 직관적이다. 예를 들어 원래 논문과 그 variant 는 공식을 증명 없이 제시한다.

대략적으로, linear attention method 는 다음 공식이 식 (10) 과 동등하다고 주장한다. 이는 합을 전개하고 index 를 주의 깊게 추적하여 검증해야 한다.

$$
Y = Q \cdot \mathrm{cumsum}(K^\top V)
\tag{14}
$$

**Proposition 4.1.** autoregressive kernel attention, 즉 causal mask 를 가진 masked kernel attention 은 step 당 constant time 이 걸리는 recurrence 로 $\mathcal{O}(T)$ 시간에 계산될 수 있다.

### 4.2.1 A Tensor Contraction Proof of Linear Attention

저자는 linear attention 에 대한 간단하고 엄밀한 유도를 제시하며, 이것이 또한 이를 어떻게 일반화할 수 있는지를 즉시 드러낸다고 본다. 핵심 아이디어는 contraction 식 (12) 를 다른 순서로 수행하는 것이다. 저자는 모호한 matrix notation 을 피하고 contraction notation 으로 직접 작업한다.

$$
Z = \mathrm{contract}(SP, SN \to SPN)(V, K)
\qquad (S, P, N)
\tag{15a}
$$

$$
H = \mathrm{contract}(TS, SPN \to TPN)(L, Z)
\qquad (T, P, N)
\tag{15b}
$$

$$
Y = \mathrm{contract}(TN, TPN \to TP)(Q, H)
\qquad (T, P)
\tag{15c}
$$

직관적으로 저자는 이 contraction 순서를 다음과 같이 해석한다.

* 첫 번째 step 인 식 (15a) 는 feature dimension $N$ 배만큼, 더 많은 feature 로 “expansion” 을 수행한다.
* 세 번째 step 인 식 (15c) 는 확장된 feature dimension 을 다시 contraction 하여 없앤다.
* 만약 $K$ 를 input 으로 본다면, $V$ 와 $Q$ 는 각각 expansion 과 contraction 을 수행한다.

두 번째 step 이 가장 중요하며, linear attention 의 linear 한 부분을 설명한다. 먼저 식 (15b) 는 단지 $L$ 에 의한 직접적인 matrix multiplication 임을 보자. 이는 $(P, N)$ axis 를 flatten 할 수 있기 때문이다. 또한 이것은 $T$ 와 $S$ axis 를 모두 포함하는 유일한 항이므로, $\Omega(TS)$ complexity, 즉 sequence length 에 대해 quadratic complexity 를 가져야 한다. 그러나 mask $L$ 이 표준 causal attention mask, 즉 lower triangular 1 의 matrix 일 때, $L$ 에 의한 matrix-vector multiplication 은 feature-wise cumulative sum 과 동일하다.

$$
y =
\begin{bmatrix}
1 \
\vdots \
1 & \cdots & 1
\end{bmatrix}
x
\iff
\begin{cases}
y_0 = x_0 \
y_t = y_{t-1} + x_t
\end{cases}
$$

## 4.3 Structured Masked Attention

masked attention 의 tensor contraction 관점인 식 (15) 을 사용하면, 원래 linear attention 의 핵심이 causal mask 에 의한 matrix-vector multiplication 이 cumulative sum operator 와 동등하다는 사실임을 즉시 알 수 있다. 그러나 저자는 attention mask 가 반드시 모두 1 일 필요는 없다고 관찰한다. linear attention 이 빠르기 위해 필요한 것은 $L$ 이 structured matrix 여야 한다는 점뿐이다. 정의에 따르면 structured matrix 는 fast matrix multiplication 을 가지는 matrix 이다.

특히, 저자는 sub-quadratic, 이상적으로는 linear 한 matrix-vector multiplication 을 가지는 어떤 mask matrix $L$ 이든 사용할 수 있으며, 이는 bottleneck 식 (15b) 를 가속함으로써 표준 linear attention 과 같은 complexity 를 가진다.

**Definition 4.2.** structured masked attention (SMA), 또는 간단히 structured attention 은 query, key, value 인 $Q, K, V$ 와, 임의의 structured matrix $L$ 에 대한 function 으로 정의된다. 여기서 $L$ 은 sub-quadratic matrix multiplication 을 가진다. 정의는 다음 4-way tensor contraction 을 통해 주어진다.

$$
Y = \mathrm{contract}(TN, SN, SP, TS \to TP)(Q, K, V, L).
$$

SMA quadratic mode algorithm 은 식 (13) 으로 정의되는 pairwise contraction 의 순서이며, 이는 표준적인 masked attention computation 에 대응한다.

SMA linear mode algorithm 은 식 (15) 로 정의되는 pairwise contraction 의 순서이며, 여기서 step (15b) 는 subquadratic structured matrix multiplication 을 통해 최적화된다.

저자는 structured masked attention 을 주어진 임의의 matrix structure class 에 대해 instantiate 할 수 있다. 몇 가지 예시는 다음과 같다.

* **Linear attention** 은 causal mask 를 사용한다.
* **RetNet** 은 decay factor $\gamma \in [0, 1]$ 에 대해 다음 decay mask 를 사용한다.
  $$
  L_{ij} = \gamma^{i-j} \cdot I[j \ge i]
  $$
* 이 decay mask 는 learnable 하거나 input-dependent 한 parameter 집합 $\alpha \in \mathbb{R}^{T}$ 에 대해 다음과 같은 Toeplitz matrix 로 일반화될 수 있다.
  $$
  L_{ij} = \alpha_{i-j}
  $$

  * 이는 relative positional encoding 의 한 형태로 해석될 수 있으며,
  * AliBi 와 같은 다른 method 를 떠올리게 하지만 additive 가 아니라 multiplicative 하다.
* 또 다른 variant 는 positional structure 를 다른 방식으로 encode 하기 위해 Fourier matrix 를 사용할 수 있다.
  $$
  L_{ij} = \omega^{ij/T}
  $$

Sec. 5 에서 저자는 semiseparable SMA 를 고려하며, 이는 저자의 주요 SSD model 을 정의한다.

### 4.3.1 Summary: The Dual Forms of Masked Attention

표준적인 masked kernel attention 은 흔히 function 과 algorithm 이 혼동된 채 다루어진다. 이 둘을 분리하면 attention 의 서로 다른 variant 를 이해하는 명확한 방법이 제시된다.

* 저자는 masked attention 을 특정한 function 인 식 (12) 로 본다.
* 표준 quadratic attention computation 인 식 (13) 은 그 function 을 계산하는 algorithm 으로 볼 수 있다.
* linear attention 인 식 (15) 은 같은 function 을 계산하는 대안적 algorithm 이다.

더 나아가, 이 경우 다음이 성립한다.

* masked attention function 은 단지 네 항에 대한 특정 contraction 이다.
* quadratic attention algorithm 과 linear attention algorithm 은 단지 contraction 을 수행하는 두 개의 다른 순서일 뿐이다.

contraction ordering 이 computation complexity 에 큰 차이를 만들 수 있다는 것은 잘 알려져 있으며, 이것이 quadratic 대 linear 의 분기를 낳는다. state space model 도 multiple way 로 계산될 수 있는 transformation 이며, quadratic form 과 linear form 이라는 dual form 을 가지는 것처럼, linear attention 역시 두 contraction order 로부터 생기는 유사한 duality 를 가진다. 실제로 이는 같은 underlying duality 에 대한 서로 다른 관점으로 드러나며, 저자는 이를 Sec. 5 에서 명시적으로 보여준다.

# 5 State Space Duality

Sec. 3 과 Sec. 4 에서 저자는 structured state space model 과 structured attention 을 정의하고, 그 성질을 논의했으며, 둘 모두가 quadratic algorithm 과 linear algorithm 을 가진다는 것을 보였다. 이 section 은 이들을 서로 연결한다. 저자의 주요 result 는 structured state space model 의 특정 case 가 structured attention 의 특정 case 와 일치하며, linear-time SSM algorithm 과 quadratic-time kernel attention algorithm 이 서로의 dual form 임을 보이는 것이다.

* Sec. 5.1 은 state space model 을 scalar structure 로 특수화하며, 여기서 naive quadratic computation 이 kernel attention 의 한 instance 로 볼 수 있음을 보인다.
* Sec. 5.2 는 structured masked attention 을 semiseparable SMA 로 특수화하며, 이는 efficient autoregression 을 가진 masked attention 을 특징짓는다.
* Sec. 5.3 은 structured masked attention 과 structured state space model 사이의 연결을 요약하며, 이를 structured state space duality 라고 부른다.

## 5.1 Scalar-Identity Structured State Space Models

Sec. 3 에서 저자는 state space model 이 semiseparable matrix transformation 과 동등하며, 그 결과 linear recurrent form 과 quadratic naive form 을 모두 가진다는 것을 보였다.

SSM 은 $y = \mathrm{SSM}(A, B, C)(x)$ 로 정의되며, SSM 의 matrix form 은 SSS representation $M = \mathrm{SSS}(A, B, C)$ 를 사용한다는 것을 상기하자. 여기서

$$
M_{ji} = C_j^\top A_{j:i} B_i
$$

이다. 이는 식 (3) 이다.

이제 $A_j$ 가 단지 scalar 인 경우를 생각하자. 다시 말해, $A$ matrix 가 극도로 structured 된 structured SSM 의 한 instantiate 이며, $A = aI$ 로 쓸 수 있다고 하자. 여기서 $a$ 는 scalar 이고 $I$ 는 identity matrix 이다. 그러면 저자는 다음과 같이 재배열할 수 있다.

$$
M_{ji} = A_{j:i} \cdot (C_j^\top B_i).
$$

그리고 이는 다음과 같이 vectorize 될 수 있다.

$$
L \coloneqq 1\mathrm{SS}(a)
$$

$$
M = L \circ (CB^\top)
$$

여기서 $B, C \in \mathbb{R}^{(T,N)}$ 이다.

이 formulation 을 사용하면, 전체 output $Y = MX$ 는 정확히 다음과 같이 계산된다.

$$
G = \mathrm{contract}(TN, SN \to TS)(C, B)
\qquad (T, S)
$$

$$
M = \mathrm{contract}(TS, TS \to TS)(G, L)
\qquad (T, S)
$$

$$
Y = \mathrm{contract}(TS, SP \to TP)(M, X)
\qquad (T, P)
\tag{16}
$$

여기서 $S = T$ 이다. 그런데 이것은 정확히 원래의 masked kernel attention 정의인 식 (13) 과 동일하다.

따라서 Sec. 3.4 에서 암시했듯이, scalar structured SSM 을 naive 하게 계산하는 것, 즉 semiseparable matrix $M$ 을 materialize 하고 quadratic matrix-vector multiplication 을 수행하는 것은 정확히 quadratic masked kernel attention 과 동일하다.

## 5.2 1-Semiseparable Structured Masked Attention

structured masked attention 은 임의의 structured mask $L$ 의 사용을 허용한다. $L$ 이 causal mask 일 때, 이는 표준 linear attention 이다. causal mask 는 $L = \mathrm{SS}(1_T)$ 임을 주목하자. 다시 말해, 1-SS mask 는 definition (6) 에서 $a_t = 1$ 로 두어 생성된다. 이것은 $L$ 을 1-semiseparable mask 의 class 로 일반화할 동기를 제공한다. 또는 1-semiseparable structured masked attention (1-SS SMA) 이라고도 한다. 여기서 linear attention 의 recurrence 에 있는 cumsum 은 더 일반적인 recurrence, 즉 scalar SSM scan, 다시 말해 1-semiseparable matrix multiplication 으로 대체된다.

마지막으로, 저자가 1-semiseparable SMA 를 고려하는 가장 중요한 이유는, 이를 계산하는 linear form 이 diagonal state space model 의 special case 이기 때문이다. SMA 의 linear form 은 식 (15) 이며, 여기서 bottleneck step 인 식 (15b) 는 1-SS mask 에 의한 matrix multiplication 으로 볼 수 있다. Sec. 3 에서 저자는 diagonal SSM 의 computation 인 식 (8) 도 썼는데, 여기서 bottleneck step 인 식 (8b) 는 scalar SSM recurrence 이며 1-SS multiplication 과 동등하다. 유일한 차이는 식 (8b) 에는 $L$ 에 extra $N$ dimension 이 있다는 점인데, 이는 matrix $A$ 가 크기 $N$ 의 diagonal matrix 이기 때문이다. 이 $N$ dimension 은 $A$ 의 모든 diagonal entry 가 같다면 사라지며, 그 결과 Corollary 5.1 이 도출된다.

**Corollary 5.1.** 1-SS SMA, 즉 1-semiseparable structured matrix $L$ 을 갖는 masked attention 식 (15) 은 diagonal matrix 가 identity 의 scalar multiple 인 diagonal SSM 식 (8) 의 special case 이다.

Corollary 5.1 은 1-SS SMA 가 efficient recurrent form 을 가진다고 말하지만, 저자는 efficient autoregression 을 가지는 SMA 의 instance 가 무엇인지 특징짓는 converse result 도 보일 수 있다.

**Theorem 5.2.** bounded order 를 가지는 autoregressive process 인 structured masked attention 의 임의의 instantiate 에 대해, structured mask $L$ 은 semiseparable matrix 여야 한다.

다르게 말하면, efficient autoregressive attention 은 general semiseparable SMA 이다. Theorem 5.2 의 증명은 Appendix C.2 에 있다.

**Remark 7.** 1-semiseparable SMA 는 state space model 의 special case 이지만, 일반적인 semiseparable SMA 는 1-SS SMA 보다 엄밀히 더 expressive 하며, 표준 SSM 으로는 기술될 수 없다. 그러나 $L$ 에 의한 semiseparable multiplication 과 SMA 의 linear form 인 식 (15a) 은 각각 expansion step 과 contraction step 을 포함하며, 이는 단일한, 더 큰 expansion 을 갖는 유사한 1-SS SMA instance 로 흡수될 수 있다.

요약하면, 1-semiseparable structured attention 은 SMA 의 가장 중요한 case 이다. 그 이유는 다음과 같다.

* input-dependent recurrence 를 가지는 linear attention 의 자연스러운 일반화이다.
* efficient autoregressive attention 과 동등한 general semiseparable attention 의 가장 단순한 case 이다.
* diagonal state space model 의 special case 이다.

## 5.3 Structured State-Space Duality (SSD)

저자의 result 를 요약하면 다음과 같다.

* structured state-space model 은 보통 linear-time recurrence 를 통해 정의되는 model 이다. 그러나 linear sequence-to-sequence transformation 을 특징짓는 matrix formulation 을 전개하면 quadratic form 을 유도할 수 있다.
* attention variant 는 quadratic-time pairwise interaction 을 통해 정의되는 model 이다. 그러나 이를 four-way tensor contraction 으로 보고 다른 순서로 reduction 하면 linear form 을 유도할 수 있다.
* 각각의 자연스러운 special case, 더 정확히는 $A$ matrix 에 scalar-identity structure 를 가진 state space model 과, $L$ mask 에 1-semiseparable structure 를 가진 structured masked attention 은 서로의 dual 이며, 정확히 동일한 linear form 과 quadratic form 을 가진다.

Fig. 4 는 이 두 representation 사이의 duality 를 요약한다.

확장된 related work 와 discussion 인 Sec. 10 은 SSD 와 일반적인 SSM 및 attention 사이의 관계를 더 자세히 설명한다.

# 6 A Hardware-Efficient Algorithm for SSD Models

SSM, attention, structured matrix 사이의 theoretical SSD framework 를 발전시키는 이점은, 이러한 연결을 사용해 model 과 algorithm 을 개선하는 데 있다. 이 section 에서 저자는 SSD model 을 효율적으로 계산하는 다양한 algorithm 이 structured matrix multiplication 을 계산하는 다양한 algorithm 으로부터 도출될 수 있음을 보인다.

저자의 주요 computational result 는 linear (recurrent) mode 와 quadratic (attention) mode 를 결합하는 SSD model 계산 algorithm 이다. 이 algorithm 은 SSM 처럼 computation 효율적이며, 즉 sequence length 에 대해 linear scaling 을 가지고, attention 처럼 hardware-friendly 하며, 즉 주로 matrix multiplication 을 사용한다.

**Theorem 6.1.** state expansion factor $N$ 과 head dimension $P = N$ 을 갖는 SSD model 을 생각하자. 임의의 input $X \in \mathbb{R}^{(T,P)}$ 에 대해 model 을 계산하는 algorithm 이 존재하며, 이 algorithm 은 training FLOPs 로 $\mathcal{O}(TN^2)$, inference FLOPs 로 $\mathcal{O}(TN)$, inference memory 로 $\mathcal{O}(N^2)$ 만을 필요로 하고, 그 work 는 matrix multiplication 이 지배한다.

이 모든 bound 는 tight 하다는 점에 주목하자. state expansion $N$ 을 가진 state space model 이 head size $N$ 에 대해 작동하면 total state size 가 $N^2$ 가 되기 때문이다. 이것은 training 및 inference FLOPs 에 대한 lower bound 인 각각 $\mathcal{O}(TN^2)$ 와 $\mathcal{O}(N^2)$ 를 준다. 또한 input $X$ 자체가 $TN$ 개의 element 를 가지므로, memory lower bound 도 따른다.

Theorem 6.1 의 핵심 아이디어는 다시 한 번 state space model 계산 문제를 semiseparable matrix multiplication 으로 보는 것이지만, 그 structure 를 새로운 방식으로 활용하는 데 있다. 전체 matrix 를 recurrent mode 또는 attention mode 로 계산하는 대신, 저자는 matrix 의 block decomposition 을 수행한다.

* diagonal block 은 dual attention mode 를 사용해 계산할 수 있으며, 이는 matrix multiplication 으로 효율적으로 수행될 수 있다.
* off-diagonal block 은 semiseparable matrix 의 rank-structure 로 factorization 할 수 있고, 더 작은 recurrence 로 환원될 수 있다.

저자는 Listing 1 이 SSD algorithm 의 self-contained implementation 을 제공한다는 점을 강조한다. Gu and Dao 의 일반 selective SSM 과 비교하면, 이 implementation 은 훨씬 더 단순하며, 특별한 low-level kernel 없이 native PyTorch 에서도 비교적 효율적이다.

시작하기 위해, 저자는 matrix $M$ 을 block size $Q$ 에 대해, 크기 $Q \times Q$ 인 submatrix 로 이루어진 $\frac{T}{Q} \times \frac{T}{Q}$ grid 로 분할한다. off-diagonal block 은 semiseparable matrix 의 defining property 에 의해 low-rank 임을 주목하자.

* **Block Decomposition**

$$
M =
\begin{bmatrix}
M^{(0,0)} \
M^{(1,0)} & M^{(1,1)} \
\vdots & \vdots & \ddots \
M^{(T/Q-1,0)} & M^{(T/Q-1,1)} & \cdots & M^{(T/Q-1,T/Q-1)}
\end{bmatrix}
$$

* **Diagonal Block**

$$
M^{(j,j)} =
\mathrm{SSM}(A_{jQ:(j+1)Q}, B_{jQ:(j+1)Q}, C_{jQ:(j+1)Q})
$$

* **Low-Rank Block**

$$
M^{(j,i)} =
\begin{bmatrix}
C_{jQ}^\top A_{jQ:jQ-1} \
\vdots \
C_{(j+1)Q-1}^\top A_{(j+1)Q-1:jQ-1}
\end{bmatrix}
A_{jQ-1:(i+1)Q-1}
\begin{bmatrix}
B_{iQ}^\top A_{(i+1)Q-1:iQ} \
\vdots \
B_{(i+1)Q-1}^\top A_{(i+1)Q-1:(i+1)Q-1}
\end{bmatrix}^\top
$$

이는 예를 통해 가장 쉽게 설명된다. 예를 들어 $T = 9$ 이고 길이 $Q = 3$ 인 chunk 로 분해한다고 하자. 음영 처리된 cell 은 semiseparable matrix 의 off-diagonal block 의 low-rank factorization 이다.

첫 번째로, 원래의 전체 matrix 는 다음과 같은 semiseparable form 을 가진다.

$$
M =
\begin{bmatrix}
C_0^\top A_{0:0} B_0 \
C_1^\top A_{1:0} B_0 & C_1^\top A_{1:1} B_1 \
C_2^\top A_{2:0} B_0 & C_2^\top A_{2:1} B_1 & C_2^\top A_{2:2} B_2 \
C_3^\top A_{3:0} B_0 & C_3^\top A_{3:1} B_1 & C_3^\top A_{3:2} B_2 & C_3^\top A_{3:3} B_3 \
C_4^\top A_{4:0} B_0 & C_4^\top A_{4:1} B_1 & C_4^\top A_{4:2} B_2 & C_4^\top A_{4:3} B_3 & C_4^\top A_{4:4} B_4 \
C_5^\top A_{5:0} B_0 & C_5^\top A_{5:1} B_1 & C_5^\top A_{5:2} B_2 & C_5^\top A_{5:3} B_3 & C_5^\top A_{5:4} B_4 & C_5^\top A_{5:5} B_5 \
C_6^\top A_{6:0} B_0 & C_6^\top A_{6:1} B_1 & C_6^\top A_{6:2} B_2 & C_6^\top A_{6:3} B_3 & C_6^\top A_{6:4} B_4 & C_6^\top A_{6:5} B_5 & C_6^\top A_{6:6} B_6 \
C_7^\top A_{7:0} B_0 & C_7^\top A_{7:1} B_1 & C_7^\top A_{7:2} B_2 & C_7^\top A_{7:3} B_3 & C_7^\top A_{7:4} B_4 & C_7^\top A_{7:5} B_5 & C_7^\top A_{7:6} B_6 & C_7^\top A_{7:7} B_7 \
C_8^\top A_{8:0} B_0 & C_8^\top A_{8:1} B_1 & C_8^\top A_{8:2} B_2 & C_8^\top A_{8:3} B_3 & C_8^\top A_{8:4} B_4 & C_8^\top A_{8:5} B_5 & C_8^\top A_{8:6} B_6 & C_8^\top A_{8:7} B_7 & C_8^\top A_{8:8} B_8
\end{bmatrix}
$$

이를 block decomposition 하면 다음과 같이 볼 수 있다.

* 각 diagonal chunk 는 그 chunk 내부의 SSM 으로 계산된다.
* 각 off-diagonal chunk 는 low-rank factorization 으로 분해된다.

예를 들어 중간 block 와 아래쪽 block 들은 다음과 같은 형태를 가진다.

$$
\begin{bmatrix}
C_3^\top A_{3:2} \
C_4^\top A_{4:2} \
C_5^\top A_{5:2}
\end{bmatrix}
A_{2:2}
\begin{bmatrix}
B_0^\top A_{2:0} \
B_1^\top A_{2:1} \
B_2^\top A_{2:2}
\end{bmatrix}^\top
$$

그리고 더 아래의 off-diagonal block 은 다음과 같이 factorization 된다.

$$
\begin{bmatrix}
C_6^\top A_{6:5} \
C_7^\top A_{7:5} \
C_8^\top A_{8:5}
\end{bmatrix}
A_{5:2}
\begin{bmatrix}
B_0^\top A_{2:0} \
B_1^\top A_{2:1} \
B_2^\top A_{2:2}
\end{bmatrix}^\top
$$

또 다른 off-diagonal block 은 다음과 같이 쓸 수 있다.

$$
\begin{bmatrix}
C_6^\top A_{6:5} \
C_7^\top A_{7:5} \
C_8^\top A_{8:5}
\end{bmatrix}
A_{5:5}
\begin{bmatrix}
B_3^\top A_{5:3} \
B_4^\top A_{5:4} \
B_5^\top A_{5:5}
\end{bmatrix}^\top
$$

여기서부터 저자는 문제를 두 부분으로 환원할 수 있다. 이는 각 “chunk” 의 output $y_{jQ:(j+1)Q}$ 를 두 component 로 나누는 것으로도 해석할 수 있다.

* chunk 내부 input $x_{jQ:(j+1)Q}$ 의 효과
* chunk 이전의 input $x_{0:jQ}$ 의 효과

## 6.1 Diagonal Blocks

diagonal block 은 더 작은 크기의 자기유사한 문제이므로 다루기 쉽다. $j$ 번째 block 은 범위

$$
R = jQ : (j + 1)Q = (jQ, jQ + 1, \ldots, jQ + Q - 1)
$$

에 대해 답

$$
\mathrm{SSM}(A_R, B_R, C_R)(x_R)
$$

를 계산하는 것을 나타낸다.

핵심은 이 block 이 원하는 어떤 method 로도 계산될 수 있다는 점이다. 특히 작은 chunk length $Q$ 에 대해서는, 이 문제를 dual quadratic SMA form 으로 더 효율적으로 계산할 수 있다. 또한 chunk 는 병렬로 계산될 수 있다.

이 subproblem 은 다음과 같이 해석할 수 있다.

* 각 chunk 에 대해, 그 chunk 로 들어가는 initial state 가 0 이라고 가정했을 때의 output 은 무엇인가

다르게 말하면, chunk $j$ 에 대해 이는 chunk input $x_{jQ:(j+1)Q}$ 만 고려하여 올바른 output 을 계산한다.

## 6.2 Low-Rank Blocks

low-rank factorization 은 3 개의 항으로 이루어지며, 이에 대응하여 계산도 세 부분으로 나뉜다. 이 factorization 에서 저자는 다음 용어를 사용한다.

* 다음과 같은 항은 right factor 또는 $B$-block-factor 라고 부른다.

$$
\begin{bmatrix}
B_0^\top A_{2:0} \
B_1^\top A_{2:1} \
B_2^\top A_{2:2}
\end{bmatrix}^\top
$$

* $A_{5:2}$ 와 같은 항은 center factor 또는 $A$-block-factor 라고 부른다.
* 다음과 같은 항은 left factor 또는 $C$-block-factor 라고 부른다.

$$
\begin{bmatrix}
C_6^\top A_{6:5} \
C_7^\top A_{7:5} \
C_8^\top A_{8:5}
\end{bmatrix}
$$

### Right Factors

이 step 은 low-rank factorization 의 right $B$-block-factor 에 의한 multiplication 을 계산한다. 각 chunk 에 대해, 이는 $(N, Q)$ 와 $(Q, P)$ 의 matrix multiplication 이다. 여기서 $N$ 은 state dimension 이고, $P$ 는 head dimension 이다. 결과는 각 chunk 에 대해 $(N, P)$ tensor 이며, 이는 확장된 hidden state $h$ 와 같은 dimensionality 를 가진다.

이는 다음과 같이 해석할 수 있다.

* 각 chunk 에 대해, 그 chunk 로 들어가는 initial state 가 0 이라고 가정했을 때의 final state 는 무엇인가

다르게 말하면, 이는 $x_{0:jQ} = 0$ 이라고 가정하고 $h_{jQ+Q-1}$ 를 계산한다.

### Center Factors

이 step 은 low-rank factorization 에서 center $A$-block-factor 항의 효과를 계산한다. 이전 step 에서 각 chunk 의 final state 는 전체 shape 이 $(T/Q, N, P)$ 이다. 이것은 이제 다음으로 생성되는 1-SS matrix 와 곱해진다.

$$
A^\times_{2Q-1:Q-1},;
A^\times_{3Q-1:2Q-1},;
\ldots,;
A^\times_{T-1:T-Q-1}
$$

이 step 은 1-SS multiplication 을 계산하는 어떤 algorithm 으로도 계산될 수 있다. 이는 scalar SSM scan 또는 cumprodsum operator 라고도 불린다.

이는 다음과 같이 해석할 수 있다.

* 모든 이전 input 을 고려했을 때, 각 chunk 에 대한 실제 final state 는 무엇인가

다르게 말하면, 이는 전체 $x_{0:(j+1)Q}$ 를 고려한 진짜 hidden state $h_{jQ}$ 를 계산한다.

### Left Factors

이 step 은 low-rank factorization 의 left $C$-block-factor 에 의한 multiplication 을 계산한다. 각 chunk 에 대해, 이는 matrix multiplication

$$
\mathrm{contract}(QN, NP \to QP)
$$

으로 표현될 수 있다.

이는 다음과 같이 해석할 수 있다.

* 올바른 initial state $h_{jQ-1}$ 를 고려하고, input $x_{jQ:(j+1)Q}$ 가 0 이라고 가정했을 때, 각 chunk 의 output 은 무엇인가

다르게 말하면, chunk $j$ 에 대해 이는 오직 이전 input $x_{0:jQ}$ 만 고려하여 올바른 output 을 계산한다.

## 6.3 Computational Cost

저자는 notation $\mathrm{BMM}(B, M, N, K)$ 를 정의하여, batch dimension $B$ 를 가지는 batched matrix multiplication

$$
\mathrm{contract}(MK, KN \to MN)
$$

을 나타낸다. 이 notation 으로부터 저자는 efficiency 의 세 가지 측면을 추론할 수 있다.

* **Computation cost:** 총 $\mathcal{O}(BMNK)$ FLOPs
* **Memory cost:** 총 $\mathcal{O}(B(MK + KN + MN))$ space
* **Parallelization:** 더 큰 $M, N, K$ 항은 modern accelerator 의 특화된 matrix multiplication unit 을 활용할 수 있다.

### Center Blocks

quadratic SMA computation 의 cost 는 세 단계로 이루어진다. 식 (16)

* kernel matrix $C^\top B$ 계산

  * cost 는 $\mathrm{BMM}(T/Q, Q, Q, N)$ 이다.
* mask matrix 와의 multiplication

  * 이는 shape $(T/Q, Q, Q)$ 의 tensor 에 대한 elementwise operation 이다.
* $X$ value 와의 multiplication

  * cost 는 $\mathrm{BMM}(T/Q, Q, P, N)$ 이다.

### Low-Rank Blocks: Right Factors

이 step 은 단일 matrix multiplication 이며, cost 는 다음과 같다.

$$
\mathrm{BMM}(T/Q, N, P, Q)
$$

### Low-Rank Blocks: Center Factors

이 step 은 길이 $T/Q$ 에 대해 $(N, P)$ 개의 독립적인 channel 위에서 수행되는 scalar SSM scan, 또는 1-SS multiplication 이다. 이 scan 의 work 는

$$
TNP/Q
$$

이며, 다른 factor 와 비교하면 무시할 수 있다.

blocking 때문에 sequence length 가 $T$ 에서 $T/Q$ 로 줄어들므로, 이 scan 의 cost 는 pure SSM scan, 예를 들어 Mamba 의 selective scan 보다 $Q$ 배 더 작다. 따라서 대부분의 problem length 에서는 다른 algorithm 이 더 효율적이거나, 큰 slowdown 없이 훨씬 구현하기 쉬울 수 있다. 예를 들어, 1-SS matrix multiplication 을 통한 naive implementation 은 다음 cost 를 가진다.

$$
\mathrm{BMM}(1, T/Q, NP, T/Q)
$$

이것은 구현이 훨씬 쉽고, naive recurrence 또는 scan implementation 보다 더 효율적일 수 있다.

### Low-Rank Blocks: Left Factors

이 step 도 단일 matrix multiplication 이며, cost 는 다음과 같다.

$$
\mathrm{BMM}(T/Q, Q, P, N)
$$

### Total Cost

만약 $N = P = Q$ 로 두면, 다시 말해 state dimension, head dimension, chunk length 를 같게 두면, 위의 모든 $\mathrm{BMM}$ 항은 다음이 된다.

$$
\mathrm{BMM}(T/N, N, N, N)
$$

이것의 computational characteristic 은 다음과 같다.

* 총 FLOP count 는 $\mathcal{O}(TN^2)$ 이다.
* 총 memory 는 $\mathcal{O}(TN)$ 이다.
* work 는 주로 shape $(N, N)$ 의 matrix 에 대한 matrix multiplication 으로 이루어진다.

memory consumption 이 tight 하다는 점에 주목하자. input 과 output 인 $x, y$ 는 shape $(T, P) = (T, N)$ 을 가진다. 한편 FLOP count 는 추가적인 $N$ factor 를 반영하는데, 이는 autoregressive state size 로 인해 드는 cost 이며 모든 model 에 공통적이다.

matmul 을 제외하면, $NP = N^2$ feature 와 sequence length $T/Q$ 에 대한 scalar SSM scan 이 있다. 이것의 cost 는

$$
\mathcal{O}(T/Q , N^2)
$$

FLOPs 이고, depth 는

$$
\mathcal{O}(\log(T/Q))
$$

이다. 비록 matrix multiplication 을 사용하지는 않지만, 여전히 병렬화 가능하며, 총 work 는 다른 step 에 비해 무시할 수 있을 정도로 작다. 저자의 GPU implementation 에서는 cost 가 무시 가능하다.

### Comparison to Pure SSM and Attention Models

quadratic attention 도 matrix multiplication 만 활용하므로 hardware efficiency 가 매우 높지만, 총 FLOPs 는 $T^2 N$ 이다. training 과 inference 모두에서 더 느린 계산 속도는 더 큰 state size 의 결과로 직접 볼 수 있다. 표준 attention 은 history 를 cache 하며 state 를 압축하지 않기 때문에, state size 가 sequence length $T$ 에 비례해 scaling 된다.

linear SSM 은 총 FLOPs 가 $TNP = TN^2$ 이며, 이는 SSD 와 동일하다. 그러나 naive implementation 은 추가 memory 를 materialize 하는 state expansion 식 (15a) 과, matrix multiplication 을 활용하지 않는 scalar operation 식 (15b) 을 필요로 한다.

저자는 다른 많은 matrix decomposition 도 가능하다는 점을 언급한다. 예를 들어 Appendix B 는 서로 다른 structured matrix decomposition 을 통한 1-SS multiplication algorithm 모음을 제공한다. 이것은 다른 특수 setting 에 더 적합한 SSD algorithm 으로 이어질 수 있다. 더 넓게는, semiseparable matrix 는 저자가 사용하는 SSS form 외에도 풍부한 문헌과 더 많은 representation 을 가지며, 더 효율적인 algorithm 도 가능할 수 있다.

# 7 The Mamba-2 Architecture

SSM 과 attention 을 연결함으로써, SSD framework 는 둘 모두를 위한 공통 vocabulary 와 technique library 를 발전시킬 수 있게 한다. 이 section 에서 저자는 원래 Transformer 를 위해 개발된 아이디어를 사용해 SSD layer 를 이해하고 수정하는 몇 가지 예를 논의한다. 저자는 여러 design choice 를 논의하며, 그 결과 Mamba-2 architecture 가 도출된다. 이러한 variation axis 는 Sec. 9.4 에서 ablation 된다.

## 7.1 Block Design

먼저 저자는 inner sequence mixing layer, 즉 핵심 SSD layer 바깥과 독립적인 neural network block 수정 사항을 논의한다.

### Parallel Parameter Projections

Mamba-1 은 SSM 중심 관점에서 동기부여되었으며, 여기서 selective SSM layer 는 $X \mapsto Y$ 인 map 으로 본다. SSM parameter $A, B, C$ 는 부수적인 것으로 간주되며 SSM input $X$ 의 function 이다. 따라서 $(A, B, C)$ 를 정의하는 linear projection 은 $X$ 를 생성하기 위한 초기 linear projection 이후에 일어난다.

Mamba-2 에서는 SSD layer 를 $A, X, B, C \mapsto Y$ 인 map 으로 본다. 따라서 block 시작 부분의 단일 projection 으로 $A, X, B, C$ 를 병렬로 생성하는 것이 타당하다. 여기서 $X, B, C$ 가 standard attention architecture 에서 병렬로 생성되는 $Q, K, V$ projection 에 각각 대응한다는 유추에 주목하자.

$A, B, C, X$ 에 대해 parallel projection 을 채택하면 parameter 수가 약간 줄어들고, 더 중요하게는 larger model 에서 tensor parallelism 에 더 적합해진다. 이는 standard Megatron sharding pattern 을 사용하기 때문이다.

### Extra Normalization

예비 실험에서 저자는 larger model 에서 instability 가 발생하기 쉽다는 것을 발견했다. 저자는 final output projection 바로 직전에 block 에 extra normalization layer, 예를 들어 LayerNorm, GroupNorm, RMSNorm 을 추가함으로써 이를 완화할 수 있었다. 이러한 normalization 사용은 NormFormer architecture 와 가장 직접적으로 관련되며, 이 architecture 역시 MLP 와 MHA block 끝에 normalization layer 를 추가했다.

또한 이 변화는 linear attention 관점에서 도출된, Mamba-2 와 관련된 다른 최근 model 과도 유사하다. 원래 linear attention formulation 은 standard attention 의 softmax function 의 normalization 을 흉내 내는 denominator term 으로 normalize 한다. TransNormerLLM 과 RetNet 은 이 normalization 이 unstable 하다는 것을 발견하고, linear attention layer 뒤에 extra LayerNorm 또는 GroupNorm 을 추가한다. 저자의 extra normalization layer 는 이들과 약간 다르며, 이전이 아니라 multiplicative gate branch 이후에 위치한다.

## 7.2 Multihead Patterns for Sequence Transformations

SSM 은 다음과 같은 sequence transformation 으로 정의된다는 점을 상기하자.

* parameter $A, B, C$ 는 state dimension $N$ 을 가진다.
* 이들은 $\mathbb{R}^{T} \to \mathbb{R}^{T}$ 인 sequence transformation 을 정의하며, 예를 들어 matrix $M \in \mathbb{R}^{(T,T)}$ 로 표현될 수 있다.
* 이 transformation 은 input sequence $X \in \mathbb{R}^{(T,P)}$ 에 대해 $P$ axis 를 따라 독립적으로 작동한다.

이는 sequence transformation 의 한 head 를 정의하는 것으로 볼 수 있다.

**Definition 7.1 (Multihead patterns).** multihead sequence transformation 은 총 model dimension $D = d_{\text{model}}$ 에 대해, $H$ 개의 독립적인 head 로 구성된다. parameter 는 head 사이에서 tied 될 수 있으며, 그 결과 head pattern 이 생긴다.

state size $N$ 과 head dimension $P$ 는 각각 attention 의 $QK$ head dimension 과 $V$ head dimension 에 대응한다. modern Transformer architecture 와 마찬가지로, Mamba-2 에서도 저자는 일반적으로 이들을 64 또는 128 정도의 constant 로 선택한다. model dimension $D$ 가 증가하면, head dimension $N$ 과 $P$ 는 고정한 채 head 수를 증가시킨다. 이를 설명하기 위해, 저자는 multi-head attention 의 아이디어를 transfer 하고 일반화하여 SSM, 또는 임의의 일반적인 sequence transformation 을 위한 유사한 pattern 을 정의할 수 있다.

### Multihead SSM (MHS) / Multihead Attention (MHA) Pattern

고전적인 MHA pattern 은 head dimension $P$ 가 model dimension $D$ 를 나눈다고 가정한다. head 수는

$$
H = D / P
$$

로 정의된다. 그 다음 각 parameter 의 독립적인 복사본 $H$ 개를 만들어 core sequence transformation 의 $H$ 개 복사본을 만든다. MHA pattern 은 원래 attention sequence transformation 을 위해 기술되었지만, Definition 2.1 과 호환되는 어떤 것에도 적용될 수 있다. 예를 들어 multi-head SSD layer 는 식 (17) 의 shape 에 따라 input 을 받고, SSD algorithm 은 $H = n_{\text{heads}}$ dimension 을 따라 broadcast 된다.

### Multi-contract SSM (MCS) / Multi-query Attention (MQA) Pattern

multi-query attention 은 attention 에 대한 영리한 최적화로, $K$ 와 $V$ tensor 를 cache 하는 autoregressive inference 의 속도를 크게 개선할 수 있다. 이 technique 은 단순히 $K$ 와 $V$ 에 extra head dimension 을 주지 않거나, 다시 말해 $(K, V)$ 의 단일 head 를 모든 $Q$ head 에 broadcast 하는 것이다.

state space duality 를 사용하면, 저자는 식 (18) 과 같은 MQA 의 동등한 SSM version 을 정의할 수 있다. 여기서 $X$ 와 $B$, 즉 attention 의 $V$ 와 $K$ 에 대응하는 SSM analog 는 $H$ 개의 head 사이에서 공유된다. 저자는 또한 이것을 multi-contract SSM (MCS) head pattern 이라고 부르는데, 이는 SSM state contraction 을 제어하는 parameter $C$ 가 head 마다 독립적인 복사본을 가지기 때문이다.

마찬가지로 저자는 multi-key attention (MKA) 또는 multi-expand SSM (MES) head pattern 도 정의할 수 있다. 여기서는 expansion 을 제어하는 $B$ 는 head 마다 독립적이고, $C$ 와 $X$ 는 head 사이에서 공유된다.

### Multi-input SSM (MIS) / Multi-value Attention (MVA) Pattern

MQA 는 KV cache 때문에 attention 에서는 자연스럽지만, SSM 에서는 자연스러운 선택이 아니다. 대신 Mamba 에서는 $X$ 가 SSM 의 주 input 으로 간주되므로, $B$ 와 $C$ 는 input channel 사이에서 공유되는 parameter 이다. 저자는 식 (20) 에서 새로운 multi-value attention (MVA) 또는 multi-input SSM (MIS) pattern 을 정의하며, 이는 다시 SSD 와 같은 어떤 sequence transformation 에도 적용될 수 있다.

이 vocabulary 를 바탕으로, 저자는 원래 Mamba architecture 를 더 정확히 특징지을 수 있다.

**Proposition 7.2.** Mamba architecture 의 selective SSM (S6) layer 는 다음과 같이 볼 수 있다.

* **Head dimension $P = 1$**: 모든 channel 이 독립적인 SSM dynamics $A$ 를 가진다.
* **Multi-input SSM (MIS) 또는 multi-value attention (MVA) head structure**: matrix $B, C$ 는 input $X$ 의 모든 channel 사이에서 공유된다.

  * attention duality 에서 $B, C$ 는 $K, Q$ 에 대응한다.
  * input $X$ 는 attention 에서 $V$ 에 대응한다.

저자는 SSD 에 적용된 이러한 head pattern variant 도 ablation 할 수 있다. 흥미롭게도, parameter 수와 total state dimension 을 통제했음에도 downstream performance 에는 눈에 띄는 차이가 있다. 실험적으로는 Mamba 에서 원래 사용된 MVA pattern 이 가장 좋은 성능을 보인다.

### Grouped Head Patterns

multi-query attention 의 아이디어는 grouped-query attention 으로 확장될 수 있다. 즉, 1 개의 $K$ 및 $V$ head 대신, $1 < G$ 이고 $G$ 가 $H$ 를 나누는 $G$ 개의 독립적인 $K$ 및 $V$ head 를 만들 수 있다. 이는 multi-query attention 과 multi-head attention 사이의 성능 차이를 줄이고, $G$ 를 shard 수의 배수로 설정함으로써 더 효율적인 tensor parallelism 을 가능하게 하려는 동기에서 나온다.

마찬가지로, Mamba-2 에서 사용되는 multi-input SSM head pattern 은 grouped-input SSM (GIS), 또는 같은 말로 grouped-value attention (GVA) 으로 쉽게 확장될 수 있다. 일반화는 직관적이므로 저자는 단순성을 위해 세부사항을 생략한다.

## 7.3 Other SSD Extensions from Linear Attention

여기서 저자는 linear attention 에서 동기부여된 SSD 에 대한 architectural modification 의 한 예를 설명한다. 저자는 이를 Sec. 9.4.3 에서 negative result 의 한 형태로 ablation 하며, default setting 으로 채택할 만큼 성능을 충분히 개선하지는 못한다는 것을 발견한다. 그럼에도 불구하고, 이는 attention 에 관한 방대한 문헌이 SSD variant 정의에 어떻게 통합될 수 있는지를 보여준다. 저자는 kernel feature map 의 선택을 Mamba-2 architecture 의 hyperparameter 로 다루며, attention 에서 영감을 받은 다른 간단한 modification 도 가능할 것으로 본다.

### Kernel Attention Approximations to Softmax Attention

linear attention 또는 kernel attention 의 많은 variant 는 attention score $\mathrm{softmax}(QK^\top)$ 를 다음 두 부분으로 보는 데서 동기부여된다.

1. exponential kernel
   $$
   Z = \exp(QK^\top)
   $$
   이는 어떤 kernel feature map 에 대해
   $$
   Z = \psi(Q)\psi(K)^\top
   $$
   로 근사될 수 있다.
2. row 합이 1 이 되도록 kernel 을 normalize 하는 단계
   $$
   M = G / G11^\top
   $$
   여기서 나눗셈은 elementwise 로 이루어지고, $1$ 은 all-1 vector 이다.

### Exponential Kernel Feature Maps

Mamba-2 에서 저자는 유연한 kernel feature map 을 도입하고, 이를 $B$ 와 $C$ branch 에 적용한다. 이들은 attention 에서 각각 $K$ 와 $V$ branch 에 대응한다. 단순성과 대칭성을 위해 feature map 은 선택적으로 $X$ branch 에도 적용될 수 있다. 이것은 Fig. 6 에서 임의의 nonlinearity 로 표현된다. 기본적으로 저자는 $\psi$ 를 elementwise Swish / SiLU function 으로 선택한다. 저자는 Sec. 9.4.3 의 ablation 에서 다른 선택지도 탐구하는데, 여기에는 Linear Attention, Performer, Random Feature Attention, cosFormer 에서 사용된 feature map 이 포함된다.

### Incorporating a Normalization (Denominator) Term

denominator term 을 찾기 위해, 저자는 단순히 $M1$ 을 계산하면 된다고 본다. 그러나 model 의 final output 이 단지

$$
Y = MX
$$

라는 점을 상기하자. 이는 식 (16) 이다. 따라서 normalization term 은 $X$ 에 extra column $1$ 을 붙임으로써 단순히 얻을 수 있다. 그러면 shape 이 $(T, P + 1)$ 인 tensor 가 된다.

이 경우 kernel feature map $\psi$ 는 합이 positive 가 되도록 positive 여야 함에 주목하자.

# 8 Systems Optimization for SSMs

저자는 large-scale efficient training 및 inference 를 위해, 특히 Mamba-2 architecture 를 중심으로 SSM 을 위한 여러 systems optimization 을 설명한다. 특히 large-scale training 을 위한 tensor parallel 과 sequence parallel, 그리고 efficient finetuning 및 inference 를 위한 variable-length sequence 에 초점을 둔다.

## 8.1 Tensor Parallel

Tensor parallelism (TP) 은 각 layer, 예를 들어 attention, MLP 를 여러 accelerator, 예를 들어 GPU 에 걸쳐 분할하여 실행하는 model parallelism 기법이다. 이 기법은 각 node 가 일반적으로 NVLink 와 같은 빠른 networking 을 갖춘 4-8 개 GPU 를 가지는 GPU cluster 에서 대부분의 large model 을 학습시키는 데 널리 사용된다. TP 는 원래 Transformer architecture 를 위해 개발되었으며, 다른 architecture 에 적용하는 것은 직관적이지 않다. 저자는 먼저 Mamba architecture 에 TP 를 사용하는 데 어떤 어려움이 있는지를 보이고, 그 다음 Mamba-2 architecture 가 TP 를 효율적으로 만들도록 어떻게 설계되었는지를 보인다.

Mamba architecture 를 상기하자. 단일 input $u \in \mathbb{R}^{L \times d}$ 가 있고, 단순화를 위해 batching 은 생략한다. input projection matrix 는 $W^{(x)}, W^{(z)} \in \mathbb{R}^{d \times ed}$ 이며, 여기서 $e$ 는 expansion factor 이고 보통 2 이다. output projection matrix 는 $W^{(o)} \in \mathbb{R}^{ed \times d}$ 이다.

$$
x = u W^{(x)\top} \in \mathbb{R}^{L \times ed}
$$

$$
z = u W^{(z)\top} \in \mathbb{R}^{L \times ed}
$$

$$
x_c = \mathrm{conv1d}(x) \in \mathbb{R}^{L \times ed}
\qquad \text{(depthwise, } d \text{ 축을 따라 독립적)}
$$

$$
\Delta, B, C = \text{low-rank projection}(x_c)
$$

$$
y = \mathrm{SSM}_{A,B,C,\Delta}(x_c) \in \mathbb{R}^{L \times ed}
\qquad \text{(} d \text{ 축을 따라 독립적)}
$$

$$
y_g = y \cdot \phi(z)
\qquad \text{(gating, 예를 들어 } \phi \text{ 가 SiLU)}
$$

$$
\mathrm{out} = y_g W^{(o)\top} \in \mathbb{R}^{L \times d}
$$

TP 에서, 계산을 2 개 GPU 에 나누고자 한다고 하자. input projection matrix $W^{(x)}$ 와 $W^{(z)}$ 를 각각 크기 $d \times \frac{ed}{2}$ 인 두 partition 으로 나누는 것은 쉽다. 그러면 각 GPU 는 크기 $L \times \frac{ed}{2}$ 의 $x_c$ 의 절반을 가진다. 그러나 $\Delta, B, C$ 가 $x_c$ 의 function 이므로, $\Delta, B, C$ 를 계산하기 전에 전체 $x_c$ 를 얻기 위해 GPU 사이에 추가 all-reduce 가 필요하다. 그 후에는 두 GPU 가 $d$ 축을 따라 독립적이므로 SSM 을 병렬로 계산할 수 있다. 마지막에는 output projection matrix $W^{(o)}$ 를 각각 크기 $\frac{ed}{2} \times d$ 인 두 partition 으로 나누고, 끝에서 all-reduce 를 수행할 수 있다. Transformer 와 비교하면, one all-reduce 대신 two all-reduce 가 필요하여 communication 시간이 두 배가 된다. large-scale Transformer training 에서는 communication 이 이미 상당한 시간, 예를 들어 10-20% 를 차지할 수 있으므로, communication 이 두 배가 되면 Mamba 는 large-scale training 에서 그만큼 효율적이지 않게 된다.

Mamba-2 에서 저자의 목표는 Transformer 의 attention 또는 MLP block 과 유사하게, block 당 one all-reduce 만 갖는 것이다. 그 결과 저자는 $\Delta, B, C$ 를 $x_c$ 로부터가 아니라 직접 $u$ 로부터 얻는 projection 을 사용하여, 이 projection matrix 들을 분할할 수 있게 한다. 이는 각 GPU 에 서로 다른 $\Delta, B, C$ 집합이 존재함을 의미하며, 이는 더 큰 “logical GPU” 위에서 여러 “group” 의 $\Delta, B, C$ 를 가지는 것과 동등하다. 또한 저자는 각 block 내에서 GroupNorm 을 사용하며, group 수를 tensor parallel degree 로 나누어떨어지게 설정하여, TP group 안의 GPU 들이 block 내부에서 서로 communicate 할 필요가 없게 한다.

$$
x = u W^{(x)\top} \in \mathbb{R}^{L \times ed}
$$

$$
z = u W^{(z)\top} \in \mathbb{R}^{L \times ed}
$$

$$
\Delta, B, C = \mathrm{projection}(u)
\qquad \text{(GPU 당 하나 이상의 } \Delta, B, C \text{ group)}
$$

$$
x_c = \mathrm{conv1d}(x) \in \mathbb{R}^{L \times ed}
\qquad \text{(depthwise, } d \text{ 축을 따라 독립적)}
$$

$$
y = \mathrm{SSM}_{A,B,C,\Delta}(x_c) \in \mathbb{R}^{L \times ed}
\qquad \text{(} d \text{ 축을 따라 독립적)}
$$

$$
y_g = y \cdot \phi(z)
\qquad \text{(gating, 예를 들어 } \phi \text{ 가 SiLU)}
$$

$$
y_n = \mathrm{groupnorm}(y_g)
\qquad \text{(group 수는 tensor parallel degree 로 나누어떨어짐)}
$$

$$
\mathrm{out} = y_g W^{(o)\top} \in \mathbb{R}^{L \times d}
$$

이제 저자는 input projection matrix 와 output projection matrix 만 분할하면 되고, block 끝에서만 all-reduce 를 수행하면 된다는 것을 알 수 있다. 이는 attention 및 MLP layer 에 대한 TP 설계와 유사하다. 특히 TP degree 가 2 인 경우,

$$
W^{(x)} = [W^{(x)}_1, W^{(x)}_2]
\qquad \text{with } W^{(x)}_i \in \mathbb{R}^{d \times ed/2}
$$

$$
W^{(z)} = [W^{(z)}_1, W^{(z)}_2]
\qquad \text{with } W^{(z)}_i \in \mathbb{R}^{d \times ed/2}
$$

$$
W^{(o)} =
\begin{bmatrix}
W^{(o)}_1 \
W^{(o)}_2
\end{bmatrix}
\qquad \text{with } W^{(o)}_i \in \mathbb{R}^{ed/2 \times d}
$$

가 된다. $i = 1, 2$ 에 대해, TP Mamba-2 layer 는 다음과 같이 쓸 수 있다.

$$
x^{(i)} = u W^{(x)\top}_i \in \mathbb{R}^{L \times ed/2}
$$

$$
z^{(i)} = u W^{(z)\top}_i \in \mathbb{R}^{L \times ed/2}
$$

$$
\Delta^{(i)}, B^{(i)}, C^{(i)} = \mathrm{projection}(u)
\qquad \text{(GPU 당 하나 이상의 } \Delta, B, C \text{ group)}
$$

$$
x^{(i)}_c = \mathrm{conv1d}(x^{(i)}) \in \mathbb{R}^{L \times ed/2}
$$

$$
y^{(i)} = \mathrm{SSM}_{A,B,C,\Delta}(x^{(i)}_c) \in \mathbb{R}^{L \times ed/2}
$$

$$
y^{(i)}_g = y^{(i)} \cdot \phi(z^{(i)})
$$

$$
y^{(i)}_n = \mathrm{groupnorm}(y^{(i)}_g)
\qquad \text{(group 수는 tensor parallel degree 로 나누어떨어짐)}
$$

$$
\mathrm{out}^{(i)} = y^{(i)}_g W^{(o)\top}_i \in \mathbb{R}^{L \times d/2}
$$

$$
\mathrm{out} = \sum_i \mathrm{out}^{(i)}
\qquad \text{(all-reduce 로 모든 GPU 의 output 을 합산)}
$$

저자는 Fig. 7 왼쪽에서 Mamba-2 의 tensor parallel 을 도식화한다.

## 8.2 Sequence Parallelism

매우 긴 sequence 에 대해서는 input 과 activation 을 sequence length dimension 을 따라 서로 다른 GPU 에 나누어야 할 수 있다. 여기에는 두 가지 주요 technique 이 있다.

1. **residual 및 normalization operation 을 위한 sequence parallelism (SP)**
   이 technique 은 먼저 제안되었으며, TP 에서의 all-reduce 를 reduce-scatter 와 all-gather 로 분해한다. residual 및 normalization operation 이 같은 TP group 의 모든 GPU 에 대해 동일한 input 에 반복된다는 점에 착안하여, SP 는 activation 을 sequence length dimension 을 따라 분할한다. 수행 순서는 다음과 같다.

   * reduce-scatter
   * residual 및 normalization
   * all-gather

   Mamba-2 architecture 는 동일한 residual 및 normalization structure 를 사용하므로, SP 는 수정 없이 적용된다.

2. **token-mixing operation, 즉 attention 또는 SSM 을 위한 sequence parallelism**
   이는 “context parallelism” (CP) 으로도 알려져 있다. attention layer 를 위해 여러 technique 이 개발되었고, 정교한 load-balancing technique 도 존재한다. attention 에서의 sequence parallelism 의 어려움은, query 와 key 를 block 으로 나눌 수는 있지만, 각 query block 이 key block 과 상호작용해야 해서 worker 수에 대해 quadratic 한 communication bandwidth 가 발생한다는 점이다.

   SSM 에서는 sequence 를 단순하게 나눌 수 있다.

   * 각 worker 가 initial state 를 받는다.
   * 자기 input 에 대해 SSM 을 계산한다.
   * final state 를 반환한다.
   * 그 final state 를 다음 worker 에 전달한다.

   communication bandwidth 는 worker 수에 대해 linear 하다. 이 decomposition 은 SSD algorithm 에서 block 또는 chunk 로 나누기 위한 block-decomposition 과 정확히 동일하다. 저자는 Fig. 7 오른쪽에서 이 context parallelism 을 도식화한다.

## 8.3 Variable Length

pretraining 에서는 batch 에 대해 같은 sequence length 를 사용하는 경우가 많지만, finetuning 이나 inference 중에는 model 이 서로 다른 길이의 input sequence 를 처리해야 할 수 있다. 이 경우를 처리하는 naive 한 방법은 batch 안의 모든 sequence 를 최대 길이에 맞추어 right-pad 하는 것이지만, sequence 길이 차이가 매우 크면 비효율적일 수 있다. Transformer 에 대해서는 padding 을 피하고 GPU 간 load-balancing 을 수행하거나, 하나의 batch 안에 여러 sequence 를 packing 하고 attention mask 를 조정하는 정교한 technique 이 개발되었다.

SSM, 특히 Mamba 에서는 variable sequence length 를 간단히 처리할 수 있다. 전체 batch 를 하나의 긴 sequence 로 취급하고, 개별 sequence 사이에서 state 를 전달하지 않으면 된다. 이는 한 sequence 의 끝에 해당하는 token $t$ 에 대해

$$
A_t = 0
$$

으로 설정하여, 그 token 이 다른 sequence 에 속한 token $t+1$ 에 정보를 전달하지 못하게 하는 것과 동등하다.

# 9 Empirical Validation

저자는 recurrent model 에게 어려웠던 synthetic recall task 에서 Mamba-2 를 실험적으로 평가하고, standard language modeling pre-training 및 downstream evaluation 도 수행한다. 또한 SSD algorithm 이 Mamba-1 보다 훨씬 더 효율적이며, 중간 정도의 sequence length 에서는 최적화된 attention 과 견줄 만하다는 것을 검증한다. 마지막으로 Mamba-2 architecture 의 다양한 design choice 를 ablation 한다.

## 9.1 Synthetics: Associative Recall

synthetic associative recall task 는 language model 이 context 안의 정보를 lookup 하는 능력을 테스트하는 데 널리 사용되어 왔다. 넓게 보면, 이 task 는 autoregressive model 에 key-value association pair 를 입력하고, 그 다음 이전에 본 key 가 주어졌을 때 올바른 completion 을 생성하도록 model 에 prompt 를 준다. multi-query associative recall (MQAR) task 는 model 이 여러 association 을 memorize 해야 하는 이 task 의 특정 formulation 이다. 원래 Mamba 논문은 관련된 synthetic task, 특히 Selective Copying 과 Induction Heads 에 대한 result 를 보고했는데, 이들은 더 쉬운 associative recall task 로 볼 수 있다. MQAR task 는 또한 “phonebook look-up” task 와도 밀접하게 관련되어 있으며, 이는 finite state capacity 때문에 SSM 과 같은 recurrent model 에게 도전적임이 알려져 있다.

저자는 더 어려운 task, 더 긴 sequence, 더 작은 model 을 사용하는 MQAR setup 의 도전적인 version 에서 비교한다. baseline 은 다음을 포함한다.

* standard multi-head softmax attention
* convolution, local attention, linear attention variant 를 결합한 Based architecture

Fig. 8 에 result 가 제시되어 있다.

* Mamba-1 은 이 task 에서 어려움을 겪는 반면, Mamba-2 는 모든 setting 에서 잘 작동한다.
* 놀랍게도, state size 를 통제했을 때조차 Mamba-2 는 Mamba-1 보다 훨씬 더 좋다.

  * 여기서 $N = 16$ 이다.
  * 저자는 architecture 의 어느 측면이 지배적인 요인인지는 확신하지 못하며, 이는 future work 에서 탐구할 문제로 남는다.
* 또한 이 task 는 state size 의 중요성을 검증한다.

  * $N = 16$ 에서 $N = 64$, $N = 256$ 으로 증가시키면 MQAR 성능이 일관되게 향상된다.
  * 더 큰 state 는 더 많은 정보, 즉 key-value pair 를 memorize 할 수 있게 하기 때문이다.

## 9.2 Language Modeling

LLM 의 표준 protocol 을 따라, 저자는 Mamba-2 architecture 를 다른 architecture 와 비교하며 standard autoregressive language modeling 에 대해 학습 및 평가한다. 저자는 pretraining metric 인 perplexity 와 zero-shot evaluation 을 모두 비교한다. model size, 즉 depth 와 width 는 GPT-3 specification 을 따르며, 125M 에서 2.7B 까지이다. 저자는 Pile dataset 을 사용하고, Brown et al. 에서 설명된 training recipe 를 따른다. 이는 Mamba 에서 보고된 setup 과 동일하며, training detail 은 Appendix D 에 있다.

### 9.2.1 Scaling Laws

baseline 으로 저자는 Mamba 와 그 Transformer++ recipe 둘 다와 비교한다. Transformer++ recipe 는 PaLM 과 LLaMa architecture 에 기반하며, 예를 들어 rotary embedding, SwiGLU MLP, LayerNorm 대신 RMSNorm, no linear bias, higher learning rate 를 사용한다. Mamba 는 이미 standard Transformer architecture, 즉 GPT-3 architecture 와, 최근의 subquadratic architecture 를 능가한다는 것을 보여주었으므로, 저자는 clarity 를 위해 그것들은 plot 에서 생략한다.

Fig. 9 는 표준 Chinchilla protocol 하에서의 scaling law 를 보여준다. model 규모는 약 125M 에서 약 1.3B parameter 까지이다.

### 9.2.2 Downstream Evaluations

Tab. 1 은 인기 있는 downstream zero-shot evaluation task 범위에 대한 Mamba-2 의 성능을, 이 크기대에서 가장 잘 알려진 open source model 과 비교하여 보여준다. 그중 가장 중요한 것은 Pythia 이며, 이는 저자의 model 과 동일한 tokenizer, dataset, training length 인 300B token 으로 학습되었다.

### 9.2.3 Hybrid Models: Combining SSD Layer with MLP and Attention

최근 및 동시대 연구는 SSM layer 와 attention layer 를 모두 가진 hybrid architecture 가 Transformer 나 pure SSM model 보다 model quality 를 향상시킬 수 있음을 시사한다. 특히 in-context learning 에서 그렇다. 저자는 각 요소의 이점을 이해하기 위해 SSD layer 를 attention 과 MLP 와 결합하는 여러 방법을 탐구한다. 실험적으로 저자는 전체 layer 수의 약 10% 를 attention 으로 두는 것이 가장 좋음을 발견한다. 또한 SSD layer, attention layer, MLP 를 함께 결합하는 것이 pure Transformer++ 나 pure Mamba-2 보다 더 잘 작동한다.

#### SSD and Attention

저자는 SSD layer 와 attention layer 가 상보적임을 발견한다.

* 각각 단독으로 보면, 예를 들어 Mamba-2 architecture 와 Transformer++ 에서는 perplexity 로 측정한 성능이 거의 동일하다.
* 그러나 SSD layer 와 attention layer 의 mixture 는 pure Mamba-2 architecture 나 pure Transformer++ architecture 보다 더 좋은 성능을 낸다.

저자는 Pile 에서 GPT-2 tokenizer 로 7B token 까지 학습한 350M model, 48 layer 에 대한 일부 result 를 Tab. 2 에 제시한다. 이 비교는 같은 parameter 수, 같은 hyperparameter, 같은 training 및 validation set 을 사용한다.

* 단 몇 개의 attention layer 만 추가해도 이미 눈에 띄는 개선이 생긴다.
* 이는 quality 와 efficiency 사이의 최상의 균형을 이룬다.

저자는 다음과 같이 가설을 세운다.

* SSM layer 는 일반적인 sequence-to-sequence mapping 으로 잘 작동한다.
* attention layer 는 model 이 모든 context 를 memory, 즉 SSM state 로 압축하도록 강제하는 대신, sequence 의 이전 token 을 빠르게 참조하는 retrieval mechanism 으로 작동한다.

#### Hybrid Models with SSD, MLP, and Attention

저자는 SSD 를 gated MLP 및 attention layer 와 결합하는 서로 다른 방식을 비교하고, 2.7B scale, 즉 64 layer 에서 평가한다. 학습은 Pile 에서 300B token 까지 진행하며, 같은 parameter 수, 같은 hyperparameter, 같은 training 및 validation set, 같은 data order 를 사용한다.

* **Transformer++:** attention layer 32 개와 gated MLP 32 개를 번갈아 배치
* **Mamba-2:** SSD layer 64 개
* **Mamba-2-MLP:** SSD 32 개와 gated MLP layer 32 개를 번갈아 배치
* **Mamba-2-Attention:** SSD layer 58 개와 attention layer 6 개

  * index 는 9, 18, 27, 36, 45, 56 이다.
* **Mamba-2-MLP-Attention:** SSD layer 28 개와 attention layer 4 개를, gated MLP layer 32 개와 번갈아 배치

저자는 Tab. 3 에 Pile validation perplexity 와 zero-shot evaluation 을 보고한다.

* 일반적으로 Transformer++ 와 Mamba-2 model 의 quality 는 비슷하다.
* 단 6 개의 attention layer 를 추가하는 것만으로도 pure Mamba-2 model, 그리고 Transformer++ 보다도 눈에 띄는 개선이 이루어진다.
* MLP layer 를 추가하면 model quality 는 감소하지만, 다음의 이점이 있을 수 있다.

  * MLP layer 의 단순성과 hardware-efficiency 때문에 training 및 inference 속도를 높일 수 있다.
  * MLP layer 를 mixture-of-experts 로 대체함으로써 MoE model 로 up-cycle 하기가 더 쉬워질 수 있다.

## 9.3 Speed Benchmarks

저자는 SSD algorithm 의 속도를 Mamba 의 scan implementation 및 FlashAttention-2 와 비교 benchmark 한다. Fig. 10 에 제시되어 있다. SSD 는 matrix multiplication 을 subroutine 으로 사용하도록 재구성되었기 때문에, GPU 의 specialized matrix multiplication unit, 즉 tensor core 를 활용할 수 있다. 그 결과, matmul unit 을 활용하지 않는 Mamba 의 fused associative scan 보다 $2 \sim 8\times$ 더 빠르다. 또한 sequence length 에 대해 linear scaling 을 가지므로, SSD 는 sequence length 가 2K 부터 FlashAttention-2 보다 더 빠르다.

그러나 저자는 Mamba-2 model 전체로 보면, 짧은 sequence length, 예를 들어 2K 에서는 Transformer 만큼 학습 효율적이지 않을 수도 있다고 지적한다. 같은 parameter 수에 대해, $L$ 개 layer 를 가진 Transformer 는 $\frac{L}{2}$ 개 MLP layer 와 $\frac{L}{2}$ 개 attention layer 를 가지는 반면, Mamba-2 model 은 $L$ 개 SSD layer 를 가지기 때문이다. 일반적으로 MLP layer 는 단순한 matrix multiplication 과 pointwise nonlinearity 로 이루어지므로 hardware efficiency 가 매우 높다. Sec. 9.2.3 에서 보였듯이, 짧은 sequence length 에서 training 속도를 높이기 위해 $\frac{L}{2}$ 개 SSD layer 와 $\frac{L}{2}$ 개 MLP layer 를 조합할 수도 있다.

## 9.4 Architecture Ablations

### 9.4.1 Block Design

Sec. 7.1 은 Mamba-2 block 을 소개했는데, 이는 Mamba-1 block 에 비해 작은 수정을 포함하며, 일부는 attention 과의 연결에서 동기부여되었고 일부는 Mamba-2 의 scalability 를 개선하기 위한 것이다. Tab. 4 는 핵심 SSM layer 바깥에서 일어나는 이 architecture 변화들을 ablation 한다.

ablation 결과는 다음을 검증한다.

* $(A, B, C, X)$ 를 생성하기 위한 parallel projection 은 Mamba 의 sequential projection 보다 parameter 를 절약하고, 성능도 약간 더 좋다.
* 더 중요하게는, 이 수정은 larger model size 에서 tensor parallelism 에 적합하다.
* extra normalization layer 역시 성능을 약간 개선한다.
* 더 중요하게는, larger scale 에서의 예비 실험은 이것이 training stability 에도 도움이 됨을 관찰했다.

### 9.4.2 Head Structure

Sec. 7.2 는 $B, C, X$ projection 의 dimension 을 multi-head attention 및 multi-query attention 의 개념과 유사한 hyperparameter 로 볼 수 있음을 설명했다. 저자는 또한 원래 Mamba architecture 가 multi-value attention 과 유사하다는 것도 보였다. 이는 state-space model 관점에서 자연스럽게 나온 선택이었으며, 이전에는 ablation 되지 않았다.

Tab. 5 는 Mamba-2 architecture 의 multi-head structure 선택을 ablation 한다. 매우 인상적으로, 저자는 multi-value pattern 과 multi-query 또는 multi-key head pattern 사이에 큰 차이를 발견한다. 겉보기에는 매우 유사하지만 그렇다. 이는 total state size 로는 설명되지 않는다는 점에 주목하자. total state size 는 모두 동일하며, head 수, head dimension, state dimension 의 곱인 $HPN$ 과 같다.

저자는 또한 $C, B, X$, 즉 attention 의 $Q, K, V$ 에 대응하는 head 수가 같은 multi-head pattern 과도 비교한다.

* standard multi-head pattern
* 모두 1 개 head 만 가지는 aggressive sharing pattern

후자의 경우에도 model 은 여전히 $H$ 개의 서로 다른 sequence mixer $M$ 을 가진다. 각 head 가 여전히 서로 다른 $A$ 를 가지기 때문이다. parameter 를 맞췄을 때, 이러한 multi-head pattern 은 서로 비슷한 성능을 보이며, MVA 와 MQA/MKA pattern 사이 중간 정도에 위치한다.

### 9.4.3 Attention Kernel Approximations

Sec. 7.3 은 SSD 가 다양한 형태의 kernel approximation 과 같이 linear attention 문헌의 아이디어와 결합될 수 있음을 언급했다. 저자는 이전 연구에서 제안된 이 variant 여러 개를 Tab. 6 에서 ablation 한다. 여기에는 다음이 포함된다.

* cosFormer
* Random Feature Attention
* Positive Random Features, 즉 Performer

저자는 또한 standard attention 의 softmax function 의 denominator 와 유사한 normalization term 을 추가하는 것도 ablation 한다. 이 항은 대부분의 variant 에 instability 를 도입했지만, activation function $\psi$ 가 ReLU 인 경우에는 성능을 약간 향상시켰다.

Tab. 7 은 feature dimension 확장을 포함하는, linear attention 을 개선하기 위한 더 최근의 제안도 테스트한다.

* Based
* ReBased

이 linear attention 확장은 quadratic approximation 으로 exp kernel 을 근사하려는 목적을 가진다. ReBased 는 또한 $QK$ activation function 을 layer normalization 으로 대체할 것을 제안한다. SSM 중심 관점에서 저자는 SSM function 을 적용하기 전에 $(B, C)$ 위에 normalization 을 적용한다.

저자는 이 technique 이 softmax attention 에 대해 “QK-Norm” 으로, 그리고 Mamba 에 대해 “internal normalization” 으로도 독립적으로 제안되었다고 언급한다.

전체적으로 Tab. 6 과 Tab. 7 은, 저자가 시도한 kernel approximation method 가 $\psi$ 에 대한 단순한 pointwise non-linear activation function 보다 나아 보이지 않는다는 것을 보여준다. 따라서 Mamba-2 의 default setting 은 Mamba-1 을 따르기 위해

$$
\psi(x) = \mathrm{Swish}(x)
$$

를 사용했다. 다만 저자는 이 activation 을 완전히 제거하는 것이, 광범위하게 테스트되지는 않았지만 더 단순한 선택일 수 있다고 제안한다.

그러나 저자는 SSD 와 vanilla linear attention 이 1-semiseparable mask $L$ 의 포함 여부에서 다르다는 점을 강조한다. 반면, 기존 문헌의 다양한 linear attention method 는 이 항 없이 softmax attention 을 근사하도록 도출되었다. 따라서 저자의 negative result 는 어쩌면 예상 밖의 일은 아닐 수 있다.

# 10 Related Work and Discussion

state space duality framework 는 SSM, structured matrix, attention 사이의 연결을 잇는다. 저자는 SSD 와 이 개념들 사이의 관계를 더 넓은 맥락에서 더 깊이 논의한다. 또한 각 관점의 아이디어를 사용하여, SSD framework 가 future work 에서 어떤 방향으로 확장될 수 있는지도 제안한다.

## 10.1 State Space Models

structured state space model 은 다음 축을 따라 특징지을 수 있다.

* time-invariant 인지 time-varying 인지
* system 의 dimensionality
* recurrent transition $A$ 에 대한 structure

SSD 는 SISO dimension 과 scalar-identity structure 를 가진 selective SSM 으로 기술될 수 있다.

### Time Variance (Selectivity)

원래의 structured SSM, 즉 S4 는 continuous-time online memorization 에서 동기부여된 linear time-invariant (LTI) system 이었다. structured SSM 의 많은 variant 가 제안되었으며, 여기에는 recurrence 를 제거하고 LTI SSM 의 convolutional representation 에 초점을 맞추는 여러 방법도 포함된다.

SSD 는 time-varying structured SSM 이며, Mamba 에서 도입된 selective SSM 이라고도 한다. Selective SSM 은 RNN 의 gating mechanism 과 밀접하게 관련되어 있다.

* 고전적인 RNN 인 LSTM 과 GRU
* 더 현대적인 variant 인 QRNN, SRU, RWKV, HGRN, Griffin

이러한 RNN 은 여러 방식에서 parameterization 이 다르며, 가장 중요한 차이는 state expansion 이 없다는 점이다.

### Dimensionality and State Expansion

SSD 의 중요한 특성 하나는, 그 계보의 이전 SSM 인 S4, H3, Mamba 와 공유되듯이, input channel 이 독립적으로 처리되는 single-input single-output (SISO) system 이라는 점이다. 이는 훨씬 더 큰 effective state size 인 $ND$ 를 낳는다. 여기서 $N$ 은 SSM state size, 즉 state expansion factor 이고, $D$ 는 표준 model dimension 이다. 전통적인 RNN 은 보통 $N = 1$ 이거나, dense $B, C$ matrix 를 가진 multi-input multi-output (MIMO) 이며, 어느 쪽이든 더 작은 state 로 이어진다.

MIMO SSM 이 일부 domain 에서는 잘 작동하는 것으로 보였지만, Mamba 는 language 와 같은 information-dense domain 에서는 state expansion 이 핵심적임을 보였다. SSD 의 주요 장점 중 하나는 model 을 느리게 하지 않으면서 더 큰 state expansion factor 를 허용한다는 점이다. 이후의 많은 연구도 state expansion 을 채택했다.

### Structure

이전 structured SSM 과 비교했을 때, SSD 의 주요 제한은 state transition $A_t$ 의 expressivity 에 있다. 저자는 diagonal $A_t$ 인 경우와 같은 더 일반적인 SSM 도 이론적 efficiency 는 SSD 와 같지만, hardware-friendly 하지 않다고 지적한다. 그 이유는 dual quadratic form 이 attention 과 같은 해석을 잃고, 계산하기 더 어려워지기 때문이다. 따라서 Mamba 와 비교하면, SSD 는 diagonal $A_t$ 의 약간 더 제한적인 형태만 사용하며, 이 expressivity 를 improved hardware efficiency 와 구현 용이성과 tradeoff 한다.

저자는 structured matrix algorithm 을 더 정교하게 만들어 일반적인 diagonal SSM case 로도 개선할 수 있을 것이라고 가정한다.

## 10.2 Structured Matrices

state space duality 의 첫 번째 관점은 이러한 model 을 matrix sequence transformation, 또는 “matrix mixer” 로 보는 관점을 취한다. 즉, sequence transformation 이 sequence dimension $T$ 를 따라 $T \times T$ matrix 에 의한 matrix multiplication 으로 표현될 수 있다는 관점이다.

이전에 여러 이러한 matrix mixer 가 제안되었으며, variation 의 주요 축은 matrix 의 representation 이다. 예를 들면 다음이 있다.

* MLP-Mixer: unstructured matrix
* FNet: Fourier Transform matrix
* M2: butterfly 또는 monarch matrix
* Toeplitz matrix
* 더 이질적인 structure 들

중요한 characterization 하나는, efficient 한 sub-quadratic matrix sequence transformation 은 structured matrix mixer 를 가지는 경우와 정확히 일치한다는 점이다. SSD framework 의 핵심 result 는 SSM 을 특정 structure, 즉 semiseparable matrix 를 가진 matrix mixer 로 보는 것이다. 그러면 linear 대 quadratic duality 는 structured matrix multiplication 대 naive matrix multiplication 의 형태를 취한다.

structured matrix representation 은 특정 semiseparable matrix 의 block decomposition 을 통해 효율적인 SSD algorithm 으로 이어졌다. Semiseparable matrix 는 scientific computing 문헌에서 잘 연구되어 왔으며, 그 아이디어를 도입하는 것은 state space model 을 더 개선할 유망한 경로일 수 있다. 또한 저자는 matrix mixer 관점에 초점을 맞추는 것이 sequence model 에 대해 더 생산적인 방향으로 이어질 수 있다고 제안한다. 예를 들어 다음과 같다.

* Mamba 의 principled 한 non-causal variant 를 설계하는 것
* softmax attention 과 sub-quadratic model 사이의 격차를 그 matrix transformation structure 를 분석하여 특징짓고 잇는 방법을 찾는 것

## 10.3 (Linear) Attention

표준적인 causal attention 과 비교했을 때, SSD 는 두 가지 주요 차이만 가진다.

첫째, SSD 는 표준 attention 의 softmax activation 을 사용하지 않는다. 이것이 attention 에 quadratic complexity 를 부여하는 요소이다. softmax 를 제거하면 linear attention framework 를 통해 sequence 를 linear scaling 으로 계산할 수 있다.

둘째, SSD 는 logits matrix 에 input-dependent 한 1-semiseparable mask 를 곱한다. 따라서 이 mask 는 표준 attention 에서의 softmax 를 대체하는 것으로 볼 수 있다.

이 semiseparable mask 는 positional information 을 제공하는 것으로도 볼 수 있다. 원소 $a_t$ 는 RNN 의미에서의 “gate”, 또는 “selection” mechanism 으로 작동하며, 이들의 cumulative product 인 $a_{j:i}$ 는 position $i$ 와 $j$ 사이에서 얼마나 많은 interaction 이 허용되는지를 제어한다. positional embedding 은 Transformer 의 중요한 구성요소이며 종종 heuristic 으로 여겨진다. SSD 의 1-SS mask 는 보다 principled 한 relative positional embedding 의 형태로 볼 수 있다. 이 관점은 GateLoop 에서도 동시에 제기되었다.

state space duality 의 두 번째 관점은 더 일반적인 structured masked attention (SMA) framework 의 special case 이며, 여기서 duality 는 단순한 4-way tensor contraction 에 대한 서로 다른 contraction ordering 으로 드러난다. SMA 는 linear attention 의 강한 일반화이며, SSD 보다도 훨씬 더 일반적이다. 다른 형태의 structured mask 는 SSD 와는 다른 성질을 가진 더 많은 efficient attention variant 로 이어질 수 있다.

attention 과의 이러한 연결은 새로운 model 로 이어질 뿐 아니라, SSM 을 이해하기 위한 다른 방향도 열어 준다. 예를 들어 저자는 attention sink 현상이 Mamba model 에도 존재하는지, 더 넓게는 interpretability technique 이 SSM 으로 이전될 수 있는지에 관심을 가진다.

마지막으로, 많은 다른 linear attention variant 도 제안되어 왔고, 저자는 많은 technique 이 SSM 으로 이전될 수 있을 것으로 기대한다.

저자는 SSD 가 표준 softmax attention, 또는 finite feature map $\psi$ 를 갖지 않는 attention kernel matrix 상의 다른 transformation 을 일반화하지는 않는다는 점을 강조한다. 일반적인 attention 과 비교했을 때 SSD 의 장점은 history 를 압축하는 controllable 한 state expansion factor $N$ 을 가진다는 점이다. 반면 quadratic attention 은 sequence length $T \gg N$ 에 따라 scaling 되는 전체 history cache 를 가진다. 동시대 연구는 copying 과 in-context learning task 에서 이러한 representation 의 tradeoff 를 연구하기 시작했다. 저자는 Mamba-2 가 이러한 capability 중 일부에서 Mamba 보다 크게 향상되었음을 언급하지만, 여전히 더 이해되어야 할 점이 많다.

## 10.4 Related Models

마지막으로 저자는 Mamba 와 Mamba-2 와 매우 유사한 sequence model 을 발전시킨 최근 및 동시대 연구의 증가하는 흐름을 강조한다.

* **RetNet 과 TransNormerLLM**

  * cumulative sum 대신 decay term 을 사용해 Linear Attention 을 일반화하고,
  * dual parallel/recurrent algorithm 과 hybrid 한 “chunkwise” mode 를 제안한다.
  * 이 algorithm 은 $A_t$ 가 time-invariant 한 SSD 의 한 instantiate 으로 볼 수 있다.
  * SMA 해석에서는 mask matrix $L$ 이 decay matrix
    $$
    L_{i,j} = \gamma^{i-j}
    $$
    이 된다.
  * 이 model 은 architecture 적으로도 여러 차이가 있다.

    * attention 중심 관점에서 유도되었기 때문에 multi-head attention (MHA) pattern 을 유지한다.
    * Mamba-2 는 SSM 중심 관점에서 유도되었기 때문에 multi-value attention (MVA) 또는 multi-expand SSM (MES) pattern 을 유지하며, 저자는 이것이 더 낫다고 보인다.

* **GateLoop**

  * input-dependent decay factor $A_t$ 의 사용을 동시에 제안했고,
  * SSD 와 동일한 dual quadratic form 을 발전시켰으며, 이를 “surrogate attention” form 이라고 부른다.

* **Gated Linear Attention (GLA)**

  * data-dependent gate 를 가진 linear attention variant 를 제안했고,
  * chunkwise mode 계산을 위한 효율적인 algorithm 과 hardware-aware implementation 을 함께 제안했다.

* **HGRN**

  * input-dependent gate 를 가진 RNN 을 도입했고,
  * 이후 HGRN2 에서 state expansion 을 포함하도록 개선되었다.

* **Griffin 과 RecurrentGemma**

  * input-dependent gating 을 가진 RNN 이 local attention 과 결합되면, 강력한 modern Transformer 와 매우 경쟁력 있을 수 있음을 보였다.
  * Jamba 역시 Mamba 와 소수의 attention layer 를 결합하면 language modeling 에서 매우 잘 작동함을 보였다.

* **xLSTM**

  * state expansion 과 다른 gating, normalization, stabilization technique 의 아이디어를 채택하여 xLSTM 을 개선한다.

* **RWKV(-4)**

  * 다른 linear attention approximation, 즉 attention-free Transformer 에 기반한 RNN 이다.
  * 최근에는 selectivity 와 state expansion 의 아이디어를 채택하여 RWKV-5/6, 즉 Eagle 과 Finch architecture 로 개선되었다.

# 11 Conclusion

저자는 잘 연구된 structured matrix class 에 기반한 theoretical framework 를 제안했으며, 이는 SSM 과 attention variant 사이의 개념적 간극을 잇는다. 이 framework 는 최근의 SSM, 예를 들어 Mamba 가 language modeling 에서 Transformer 만큼 잘 작동하는 이유에 대한 통찰을 제공한다. 더 나아가, 저자의 theoretical tool 은 양쪽의 algorithm 및 system 발전을 연결함으로써 SSM, 그리고 잠재적으로는 Transformer 를 개선할 새로운 아이디어를 제공한다. 그 시연으로서, 이 framework 는 SSM 과 structured attention 의 교차점에 있는 새로운 architecture, 즉 Mamba-2 의 설계를 이끈다.
